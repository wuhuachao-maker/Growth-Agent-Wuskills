# 内容诊断检查清单

> 一份可复用的「内容体检表」。适用于公众号文章、小红书笔记、抖音口播前的自查，或诊断一条「数据不好」的内容。
> 每项是「过关条件」，任一不过关，就是该内容的短板。

---

## 一、标题体检（权重 30%）

- [ ] **清晰度**：不看正文，能猜出这条讲什么？（模糊 ❌ / 明确 ✅）
- [ ] **钩子力**：前 8 字是否戳中痛点 / 制造好奇 / 给利益？
- [ ] **平台适配**：小红书带情绪词？公众号带观点？抖音带悬念？
- [ ] **搜索可发现**：是否含 1–2 个目标关键词（SEO/GEO 友好）？
- [ ] **红线**：无极限词、无夸大、无标题党（点了不骂人）？

## 二、开头体检（权重 25%）

- [ ] **3 秒钩子**：前 3 秒/前 2 行是否让人想继续？
- [ ] **痛点共鸣**：是否精准描述用户的「此刻困境」？
- [ ] **承诺明确**：是否暗示「看完能得到什么」？
- [ ] **无废话**：前 30 字没有「今天给大家分享」这类无效开场？

## 三、结构体检（权重 20%）

- [ ] **逻辑链**：论点→论据→结论，是否顺？
- [ ] **节奏感**：是否分段、有小标题、有视觉留白？
- [ ] **信息密度**：每屏都有新信息，无注水？
- [ ] **案例支撑**：观点是否有真实案例/数据背书？

## 四、价值体检（权重 15%）

- [ ] **可行动**：看完用户知道「下一步做什么」？
- [ ] **可迁移**：方法能否套用到用户自己的业务？
- [ ] **有观点**：不是搬运，有你的独特判断？

## 五、转化体检（权重 10%）

- [ ] **CTA 单一**：只引导一个动作（关注 / 加微 / 看下篇）？
- [ ] **低门槛**：动作是否不需用户付出高成本？
- [ ] **私域衔接**：是否有路径把公域用户导进私域？

## 评分卡

| 维度 | 权重 | 自评(0-10) | 加权分 |
|---|---|---|---|
| 标题 | 30% | | |
| 开头 | 25% | | |
| 结构 | 20% | | |
| 价值 | 15% | | |
| 转化 | 10% | | |
| **总分** | 100% | | |

- **≥ 80**：可发，优等
- **60–79**：能发，但有明显短板待修
- **< 60**：先改再发，重点补最低分项

---

## 使用方式

1. 发内容前：逐项打勾，不过关的当场改。
2. 数据差时：用清单定位「哪维度塌了」，针对性优化。
3. 本清单是「内容诊断」类任务的结构化输出模板，可配合对应 skill 或商业版使用。
