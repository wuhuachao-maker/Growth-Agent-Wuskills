# 内容获客高频概念词典

> 本词典为 Growth Flow Agent 内容获客体系的核心术语口径。Skill 与使用者应统一使用下列定义，避免概念混用。

---

## 1. SEO（搜索引擎优化）
通过关键词布局、结构优化、外链等手段，提升内容在搜索引擎（Google / 百度 / 微信搜一搜）中的自然排名。
- **核心指标**：收录、排名、点击率（CTR）、长尾词覆盖。
- **适用场景**：公众号文章、知乎回答、官网博客。

## 2. GEO（生成式引擎优化 / Generative Engine Optimization）
针对 AI 问答引擎（ChatGPT / 豆包 / 文心一言 / Perplexity）的内容优化。让 AI 在回答用户问题时，优先引用、提及你的品牌或内容。
- **核心机制**：AI 偏好引用「结构清晰、有权威来源、被多处提及」的内容。
- **与 SEO 区别**：SEO 争排名位次，GEO 争「被 AI 引用」。
- **实操**：在内容中明确写出品牌名、核心观点、数据来源；做多平台一致发声。

## 3. 公域 vs 私域
- **公域**：平台流量（抖音、小红书、公众号推荐流），靠平台算法分发，不归你所有。
- **私域**：你可直接触达的用户资产（微信好友、社群、公众号粉丝），可重复免费触达。
- **关系**：公域负责拉新，私域负责留存与复购。

## 4. 私域
沉淀在微信个人号 / 社群 / 公众号粉丝里的可重复触达用户。核心价值是「免费、可控、可迭代」。

## 5. IP（个人/品牌 IP）
具有稳定人格、鲜明观点、持续内容输出的账号主体。IP 的本质是「信任资产」——用户因信你而买你。
- **IP 三要素**：人格（你是谁）、观点（你信什么）、内容体系（你持续产出什么）。

## 6. 矩阵
同一主体下多个账号协同分发，覆盖不同人群/平台，降低单账号封禁或限流风险，放大声量。
- **常见形态**：主号 + 垂类小号 + 平台分发号。

## 7. 钩子（Hook）
内容开头 3 秒内抓住注意力的设计。常见钩子类型：反常识、痛点共鸣、悬念、利益承诺、身份认同。

## 8. CTA（Call To Action，行动召唤）
引导用户做下一步动作的设计：关注、点赞、评论、加微信、点链接。好的 CTA 必须「单一、明确、低门槛」。

## 9. 转化漏斗
用户从「看到内容」到「完成目标动作」的路径：
```
曝光 → 点击 → 阅读/观看 → 互动 → 关注/加微 → 成交
```
每一层都有流失，优化的本质是「抬高每一层的通过率」。

## 10. 内容支柱（Content Pillar）
支撑一个 IP 的 3–5 个核心内容主题。例如「获客方法论 / 案例拆解 / 工具实测 / 行业观点」。支柱稳定，账号才不会今天发这个明天发那个。

## 11. JTBD（Jobs To Be Done，待办任务）
用户「雇」你的内容/产品，是为了完成什么进展。写内容前先问：用户此刻想推进什么？是什么力量推他、什么力量拉他？

## 12. 冷启动
新账号/新内容在没有粉丝基础、没有算法偏好的阶段，靠人工分发（社群、朋友圈、互推）拿到首批数据，撬动算法推荐。

## 13. 算法推荐逻辑（通用）
平台用「完播率 / 互动率 / 停留时长 / 关注转化」等信号判断是否继续推流。前 100–500 次曝光的反馈，决定一条内容的命运。

## 14. 完播率 / 互动率
- **完播率**：看完的人数 / 看到的人数。短视频生命线。
- **互动率**：点赞+评论+收藏+转发 / 曝光。算法推流的核心燃料。

## 15. 搜索可发现性（Searchability）
用户通过搜索主动找到你的能力。SEO 管「搜得到」，GEO 管「AI 答得出」，两者共同构成「被找到」的总带宽。
