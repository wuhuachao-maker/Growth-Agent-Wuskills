## 一句话介绍

把你在「做内容、获流量、转私域」过程中遇到的真实问题直接说给 Agent，它会调用对应的 skill，给你可执行的方法论与下一步。

所有 skill 都是**方法论免费版**：教你做、给你模板、帮你诊断；但不会替你跑私有数据、不会接你的付费 API、不会开放 license 逻辑。

## 安装

### 方式一：一条命令安装到所有客户端（推荐）

```bash
npx -y skills add wuhuachao-maker/Growth-Agent-Wuskills -g --all
```

安装后重启你的 Agent 工具即可使用。

### 方式二：只装到指定客户端

**WorkBuddy**

```bash
curl -sL https://raw.githubusercontent.com/wuhuachao-maker/Growth-Agent-Wuskills/main/bridge/install.sh | bash -s -- --target workbuddy
```

**Claude Code**

```bash
curl -sL https://raw.githubusercontent.com/wuhuachao-maker/Growth-Agent-Wuskills/main/bridge/install.sh | bash -s -- --target claude
```

**Codex / Cursor / 其他支持 Skills 的 Agent**

```bash
curl -sL https://raw.githubusercontent.com/wuhuachao-maker/Growth-Agent-Wuskills/main/bridge/install.sh | bash -s -- --target agents
```

### 方式三：交互式安装

如果你不确定自己的 Agent 客户端装在哪，运行交互式脚本：

```bash
curl -sL https://raw.githubusercontent.com/wuhuachao-maker/Growth-Agent-Wuskills/main/bridge/install-interactive.sh | bash
```

## 使用方法

安装完成后，直接在对话里描述你的问题。Agent 会根据触发词自动匹配 skill。

### 直接命中

| 你说 | 触发的 skill |
|---|---|
| "帮我起 10 个小红书标题" | `multi-platform-title` |

### 通过 _hub 路由

如果你不确定该用哪个 skill，直接说：

- "我想做内容获客"
- "帮我看看这个账号怎么涨粉"
- "我的文章流量不好，帮我诊断一下"

`_hub` 会先澄清你的目标，再把你交给最合适的 skill。

## 更新与卸载

### 更新

重新运行安装命令即可增量更新：

```bash
npx -y skills add wuhuachao-maker/Growth-Agent-Wuskills -g --all
```

或对你的 Agent 说：

```
更新 Growth Flow Agent 技能集合
```

### 卸载

如果你之前用 `bridge/install.sh` 安装到指定客户端：

```bash
curl -sL https://raw.githubusercontent.com/wuhuachao-maker/Growth-Agent-Wuskills/main/bridge/install.sh | bash -s -- --target workbuddy --uninstall
```

如果是通过 `npx skills add` 安装，删除对应客户端 skills 目录下的 `Growth-Agent-Wuskills` 软链即可。

## FAQ

**Q：安装后 Agent 没反应？**

1. 重启 Agent 工具。
2. 确认 skill 已出现在客户端的 skills 目录。
3. 直接说触发词，例如 "帮我起 10 个小红书标题"。

**Q：我可以改这些 skill 自己用吗？**

可以，但仅限个人/非商业用途，且需保留 CC BY-NC 4.0 声明。商业使用请联系作者授权。
