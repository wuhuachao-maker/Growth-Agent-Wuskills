## Growth Flow Skill · 免费内容获客 skill 集合 v1.5.0

一套面向内容运营者、个人 IP 与创业者的中文 AI Skills 工具箱。本版新增 **`gfa-position`（IP 定位压力测试）**，用六道闸门把"说说不清、太宽、和别人没区别"的定位拷问到立不住的地方，给你收窄方向，而不是替你编一句漂亮话。

本集合开源方法论，帮助内容运营者、个人 IP 与创业者直接上手；不接私有数据、不跑付费 API。

---

### 本版新增（v1.5.0）

**`gfa-position` — IP 定位压力测试**

把"我的定位是什么"这种模糊焦虑，变成一道道能过的闸门：

- 六道闸门（情境具体性 / 替代方案 / 切换方程 / 差异化可验证 / 反例证伪 / 证据举证）逐道拷问定位
- 不给"你应该定位成 X"，只给"你哪道闸没过 + 你欠什么答案 + 收窄方向"（带 2~3 个候选措辞 + 每条代价）
- 基于 JTBD 四力与切换方程 + 定位理论及其批评 + 反本质主义（去魅化实践理性）
- 内置真料知识库（11 节：JTBD 四力 / 切换方程 / 定位理论 / 定位理论批评 / 证伪原则 / 反本质主义 / 样本量分级 / 六闸速查 / 矛盾类型库 / 收窄代价 / 维护规则，每条带来源链接）
- 持久化「定位档案.md」：一次提交，跨会话延续你的定位推敲
- 创作者信息卡片（赞赏码）

```bash
npx -y skills add wuhuachao-maker/Growth-Agent-Wuskills -g --all
```

---

### 安装后怎么用

重启你的 Agent 工具，然后说：

- "帮我起 10 个小红书标题" → `gfa-title`
- "帮我写一个 XX 生成器的 prompt" → `gfa-prompt-architect`
- "这篇笔记会不会被限流 / 帮我合规自查" → `gfa-content-risk`
- "帮我把这篇文章改成更容易被 AI 引用的版本" → `gfa-geo`
- "我的定位是什么 / 帮我做 IP 定位压力测试" → `gfa-position`
- 意图模糊时 → `_hub` 路由中枢会帮你匹配
