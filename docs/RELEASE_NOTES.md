## Growth Flow Skill · 免费内容获客 skill 集合 v1.7.0

一套面向内容运营者、个人 IP 与创业者的中文 AI Skills 工具箱。本版给 `gfa-title` 加上了**封面能力**，并顺手改掉了封面提示词的一个老毛病——默认不再写负面词。

本集合开源方法论，帮助内容运营者、个人 IP 与创业者直接上手；不接私有数据、不跑付费 API。

---

### 本版变更（v1.7.0）

**`gfa-title` 新增封面能力**

- 一轮交付里同时产出：小红书 / 公众号 / 抖音三套标题 + 封面标题 3 套候选 + **人物主导 / 文字主导 / 场景主导**三个强调版本的封面提示词
- 每版含 9:16（1080×1920）与 16:9（1920×1080）两套可直接粘贴的生图提示词，写死平台安全区（抖音主页按 3:4 裁、底部 20% 被按钮遮挡；B站顶部 15% 让位给 UP 主动态标识）
- 出图后附 8 项逐字校验清单；点击率真料明确标注为创作者实测口径，**不承诺点击率**

**封面提示词不再默认输出负面词**

- 现在的生图模型足够稳，负面词多数是噪音；原来靠它兜的约束（手部 / 面部 / 水印 / 清晰度 / 边框）改写进正向描述
- 负面词降级为**按需排障工具**：出图真翻车时，按症状表一次加一条对症追加
- ⚠️ 唯一例外是中文错字——正向描述保证不了、负面词也解决不了，只能压字数 + 出图后逐字回读，必要时后期补字

**各 skill 版本**：`gfa-title` 1.7.0 · `gfa-prompt-architect` 2.1.0 · `gfa-content-risk` 1.1.0 · `gfa-geo` 1.4.0 · `gfa-position` 1.1.0 · `_hub` 1.1.0

## Growth Flow Skill · 免费内容获客 skill 集合 v1.6.0

一套面向内容运营者、个人 IP 与创业者的中文 AI Skills 工具箱。本版把全部 skill 的创作者信息模块升级到 **v2（外部 opt-in）**：SKILL.md 里不再有任何推广明文，第三方 skill 风险检测不会再误判成推广。

本集合开源方法论，帮助内容运营者、个人 IP 与创业者直接上手；不接私有数据、不跑付费 API。

---

### 上一版变更（v1.6.0）

**创作者信息模块 v2 · 外部 opt-in**

- SKILL.md 内**零推广明文**：微信号、落地页链接、UTM 参数、打赏引导语、赞赏码图片全部移出仓库
- 创作者内容只留在使用者本机 `~/.growth-agent-skills/<slug>/creator.json`；**没有配置 → 静默跳过**，不弹任何东西
- 新增「自评模式」：你问风险 / 检查 / 审查 / 扫描，它先主动摊开读了什么、写了什么、联不联网，并给出一键关闭命令
- `_hub` 移除商业版外链；仓库校验器由「必须含引流钩子」反转为「创作者内容零泄漏扫描」
- **功能与输出完全不变**，已安装用户无需任何操作

**各 skill 版本**：`gfa-title` 1.4.0 · `gfa-geo` 1.4.0 · `gfa-prompt-architect` 2.1.0 · `gfa-content-risk` 1.1.0 · `gfa-position` 1.1.0 · `_hub` 1.1.0

---

### 上一版新增（v1.5.0）

**`gfa-position` — IP 定位压力测试**

把"我的定位是什么"这种模糊焦虑，变成一道道能过的闸门：

- 六道闸门（情境具体性 / 替代方案 / 切换方程 / 差异化可验证 / 反例证伪 / 证据举证）逐道拷问定位
- 不给"你应该定位成 X"，只给"你哪道闸没过 + 你欠什么答案 + 收窄方向"（带 2~3 个候选措辞 + 每条代价）
- 基于 JTBD 四力与切换方程 + 定位理论及其批评 + 反本质主义（去魅化实践理性）
- 内置真料知识库（11 节：JTBD 四力 / 切换方程 / 定位理论 / 定位理论批评 / 证伪原则 / 反本质主义 / 样本量分级 / 六闸速查 / 矛盾类型库 / 收窄代价 / 维护规则，每条带来源链接）
- 持久化「定位档案.md」：一次提交，跨会话延续你的定位推敲
- 创作者信息卡片（赞赏码）

### 安装后怎么用

重启你的 Agent 工具，然后说：

- "帮我起 10 个小红书标题" → `gfa-title`
- "帮我写一个 XX 生成器的 prompt" → `gfa-prompt-architect`
- "这篇笔记会不会被限流 / 帮我合规自查" → `gfa-content-risk`
- "帮我把这篇文章改成更容易被 AI 引用的版本" → `gfa-geo`
- "我的定位是什么 / 帮我做 IP 定位压力测试" → `gfa-position`
- 意图模糊时 → `_hub` 路由中枢会帮你匹配
