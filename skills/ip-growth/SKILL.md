# 个人 IP 增长方法论

## 核心哲学

IP 增长不是"赌一条爆款"，而是**用稳定的人设 + 系统化的内容 + 可度量的漏斗**，把陌生流量逐步变成信任与转化。本 skill 教你搭一套"即使某条没火也不崩"的增长系统。

## 工作模式

- **定位先行**：没定位不碰内容；人设 = 你持续能提供、且市场愿意听的那件事。
- **系统 > 灵感**：内容靠选题库与节奏驱动，不靠临时拍脑袋。
- **漏斗思维**：每个 IP 都要想清"流量→信任→转化"三段分别靠什么承接。

## 标准流程（五步）

**步骤 1 · 定位与人设**：用"你能持续输出什么 × 市场缺口 × 你不可替代的视角"三角锁定定位；写下一句话人设（给谁、解决什么、凭什么信你）。

**步骤 2 · 内容系统搭建**：
- 建选题库（常青选题 + 热点选题 + 转化选题三类）。
- 定内容支柱（3–5 个反复讲的主题，构成你的"知识地图"）。
- 定每类内容的产出节奏与格式。

**步骤 3 · 转化漏斗设计**：
- 注意力层（标题/封面/开头）：负责被看见。
- 信任层（专业内容/案例/人设故事）：负责被信。
- 转化层（留资/加微/预约/购买）：负责被转化；明确每个 IP 的主转化动作。

**步骤 4 · 节奏与一致性**：定发布频率、人设语气一致性规则；用"系列化"降低单条风险（一个系列火了带起全部）。

**步骤 5 · 度量与迭代**：定北极星指标（如有效留资数而非单纯阅读）+ 2–3 个过程指标（完读/互动/转发）；按数据回流选题库。

## 输出格式（模板 A/B/C）

- **A · IP 搭建蓝图**（默认）：定位句 + 内容支柱 + 漏斗设计 + 节奏规则 + 度量指标。
- **B · 定位卡**：只给一句话人设 + 3–5 内容支柱。
- **C · 漏斗图**：注意力/信任/转化三层 + 每层承接动作与指标。

## 典型场景

- 想从 0 起一个内容 IP 但不知从哪开始。
- 有账号但涨粉慢、转化弱，要系统梳理。
- 小团队想用 1–2 人跑通 IP 获客。

## 说话风格

务实、给框架、给动作；不画大饼；强调"系统>爆款"。

## 语言

中文。
