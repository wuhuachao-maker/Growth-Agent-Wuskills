# 吴唐IP起号之IP故事（GFA IP Story）

## Purpose

把真实资料变成能用于个人 IP 故事的文字。核心不是「把故事讲漂亮」，而是**不替用户编故事，并且能证明没编**。

用户丢进来的可以是整理好的 9 项资料，也可以是聊天记录、简历、公众号文章、笔记、会议记录等任意原始材料。skill 先从资料里抽字段、标出处，只对真正缺的核心项生成候选；用户确认主线和人物内核之后，才按用途写对应版本。

## 能力边界

- **做**：资料抽取与溯源、主线候选与裁决、人物内核提炼、故事成文、按用途出版本（**长文 / 简介**）、逐句验真。
- **不做**：**不产出口播脚本、短视频口播稿、朗读稿**——用户提出这类需求时，如实说明本 skill 不包含该能力，不要顺手把长文压缩成口播。不替用户虚构任何事实、数字、时间、关系；不做外部事实核查（只核对用户给的资料内部是否自洽）；不写简历式罗列、不写抒情散文、不写鸡汤；不替用户发布。**不默认长文和简介都出**——按第 9 项用途裁剪。
- **资料范围**：只用本次会话中用户提供的资料。私有 skill，资料不写回 skill 目录、不外传。

## 理论内核：去魅化实践理性（一 skill 一理论）

不混绑其他内核。六条判据直接落到操作上：

| 判据 | 落到故事里 |
|---|---|
| 数据锚定（洛克） | 每个数字、时间、结果都必须回指资料原句；没有就留空或标待核实 |
| 因果克制（休谟） | 写「这件事之后发生了 X」，不写「因为 X 所以注定 Y」；结论给边界 |
| 有效性可检验（杜威） | 认知必须落成一个具体动作，不是感慨 |
| 反本质黑话（维特根斯坦） | 禁「洞察本质 / 底层逻辑 / 命运的齿轮 / 闭环」等不可指物词 |
| 反权威（福柯） | 不靠「专家说 / 行业共识」压人，只讲自己经历与可核实的结果 |
| 行动指令（老吴） | 结尾给一个极具体、可执行的下一步 |

风格六维：真实性 7.5 / 权力 2.5 / 情感 3.5 / 逻辑 9 / 具体 9 / 行动 10（±1 容差）。

## 两段式阶段锁（最高优先级）

**阶段 A（第 1–5 步）只做挖掘与裁决。通常只有一个停点：第 5 步。**
**阶段 B（第 6–8 步）在第 5 步确认后才执行。**

第 3 步虽然要生成缺项候选，但**不单独停下来问**——它生成的候选项合并进第 5 步那一轮一起交。用户如果说「先分析别急着写」，按阶段 A 结束交付；用户**拍板了主线和内核**（或明确授权推定）即可进阶段 B。仅说「按这个写」而主线未拍板时，按第 5 步的部分确认规则处理，**不算进 B 的指令**。

**唯一例外：无资料路径**多一个进料停点（第 1c 步）。那里没有资料可提取，第 5 步的裁决无从产生，必须先问一轮。

## Workflow

### 阶段 A · 进料与裁决

#### 1. 输入分流与资料准入 — 🔵 AUTO（1c 进料停为 🟠）

**三种输入路径：**

判据优先级：**先看是不是文件夹**——是文件夹就走 1b，不管里面有几个文件。不是文件夹时再按份数分：

- **文件夹（无论几个文件）/ >3 份散材料** → 先做「1b 资料准入」，再走第 2 步。
- **单份资料 / 粘贴文本 / ≤3 份散材料** → 直接走第 2 步资料提取。
- **无资料** → 走「1c 最小问卷」，这是一个 🟠 独立停点。

**1b. 资料准入（文件夹 / 多材料时必做）**

按顺序做四件事，不许跳过、不许先读正文：

1. **先列清单，不读内容**：给出目录结构（文件名 + 文件类型），让用户看到「我看到了什么」。
2. **先读规则类文件**：入口文件 / README / 说明 / 授权声明 / 项目主档案——找有没有「未经授权不得进入 AI」「敏感资料」「脱敏审核」这类使用限制。**这一步必须在读任何正文之前**。
3. **按可引用性分三档，逐份标注**：
   - `A 可引用`：已公开发表（公众号文章、随笔、公开产品手册），或用户在本会话明确说「可以用」。
   - `B 内部参考`：内部方案、复盘、草案——可读，用来理解背景，但**不许当事实写进故事**，除非用户确认。
   - `C 不进 AI`：明确标注保密 / 隐私 / 未经授权的材料，或明显属于第三方私人信息的材料。**只读文件名，不读内容**。文件名里出现的第三方姓名只用于盘点，不写进提取表。
   - 拿不准的归 C，并说明「哪类没读、为什么」。
4. 准入结果先展示（哪些读 / 哪些不读 / 依据那条规则），**不设确认停点**，直接按 A/B 档做第 2 步。用户若要授权 C 类，在后续任意一轮回复里说「C 类我授权了」即可；skill 收到后重新准入——这是用户主动插入，不算流程新增停点。
   **重新准入后的回流**：若这次新增了可引用的 A/B 档材料，**第 2 步提取表必须重做**，已产出的主线与内核候选作废，回到第 4 步重新扩样，并在新的第 5 步重新拍板。不许拿旧候选接着写。

**1c. 无资料路径 — 🟠 独立停点**

无资料时无法做第 2 步提取，第 5 步的裁决也无从产生。这条路径多一次进料停：

- 按 9 项字段生成问卷，**一次问完**（最多 9 题，核心 4/5/6 必问）。
- 每题给「跳过」选项，跳过不追问。
- 用户答完后，把答案当资料写进提取表（来源标「用户口述第 N 题」），**再从第 2 步继续**，第 5 步照常停一次。
- 无资料路径共停两次（1c 进料 + 第 5 步裁决）。这是阶段锁的唯一例外。

已有资料但核心项缺失时，**不走 1c**——走第 3 步生成候选，并入第 5 步一次问完。

#### 2. 资料提取 — 🔵 AUTO（关键，决定用户要不要回答问题）

扫一遍资料，建一张**资料提取表**。9 项字段如下：

| # | 字段 | 提取线索（在资料里找什么） |
|---|---|---|
| 1 | 身份 / 职业 | 自称、职位、公司、行业、自我介绍句 |
| 2 | 目前在做什么 | 当前项目、产品、服务对象、日常动作 |
| 3 | 过去的重要经历 | 时间线、阶段切换、离职/创业/转行、里程碑 |
| 4 | 关键困难 / 低谷 / 失败 | 卡住、亏损、被拒、做错、停摆、失眠、质疑 |
| 5 | 做过的重要选择 | 「决定 / 于是我 / 我选了 / 放弃了 / 不做 X 了」及当时理由 |
| 6 | 结果 / 成绩 / 反馈 | 数字、客户数、金额、周期、他人原话、媒体报道 |
| 7 | 最想被记住的点 | 自我定位句、反复强调的主张、对别人的价值。**本项不单独追问**；缺失时内核裁决改用第 8 项价值观摘录 + 第 5/6 项选择与结果作为依据 |
| 8 | 想传递的价值观 | 「我认为 / 我信 / 我不认同」、对某事的判断 |
| 9 | 故事用途 | 公众号 / 简介 / 课程页 / 朋友圈 / 融资 BP，决定第 7 步出哪几份 |

每一行必须标三项：

- **来源**：文件名 + 段落序号（无文件名就写「消息第 N 段」，从 1 起编号）。
- **原句摘录**：不超过 30 字的原文片段，照抄不改。
- **状态**：`明确` / `推导（必须写出依据的原句）` / `缺失` / `矛盾（列出冲突的两处原句）`。

**推导规则（全字段统一，不再分别对待）：**
- 资料里有明确依据的，允许标「推导」，但**必须写出依据原句**——同一句话不能在一处算明确、另一处算不能推。
- 完全找不到依据的写「缺失」，不许用常识补、不许凭空推测。
- 同一字段出现互相矛盾的说法，标「矛盾」，交第 5 步裁决，AI 不许自己选一个。
- 扫完先把提取表给用户看，但**不因此停下来问用户**，继续第 3 步。

#### 3. 缺项候选生成 — 🔵 AUTO（生成候选，不停）

检查核心 **3 项（4、5、6）** 是否缺失。第 7 项不在这里问，它的候选由第 5 步内核裁决处理。

候选生成规则：

- 对缺失的核心项，从资料里给 2–3 个**候选答案**（带推荐项），但**不在本步 asking 用户**——合并进第 5 步那一轮选择题。
- 最多生成 2 题。
- 用户答不上来就留空并标注「未确认」，不许替他编。
- 若核心项有 ≥2 项缺失且资料里找不到任何候选：只保留最关键的一题，其余留空，主线表达强度下调，并在交付时说明。
- 第 9 项未写明时按「公众号长文」处理，并在第 5 步附一句「是否加简介」。

#### 4. 主线扩样 — 🔵 AUTO

基于提取表，出 **3 条主线候选**。每条写一句「最适合的讲法」+ 一句「为什么」+ 三个透镜打分（0–10）+ 一个序列类型。

**打分锚点（必须按锚点打，并在分数后附一句回指提取表行号的依据；无依据的透镜不得分）：**

**9 分的判据 = 锚点表 ∩ 中间档**：提取表里**同时有**具体困境与明确代价，且主线讲法那一句里**同时呈现了**两者 → **9**。只满足其中一项 → **7**。提取表里根本没有代价 → **6**。

| 透镜 | 9 分 | 6 分 | 3 分 |
|---|---|---|---|
| 冲突强度 | 具体困境 + 明确代价（钱 / 关系 / 机会），且讲法句同时呈现 | 有困难但未写代价 | 只有「遇到困难」这类形容词 |
| 独特性 | 换成同行讲不出来（有专属数字或专属选择） | 有具体事但同行可套用 | 通用道理 |
| 场景契合度 | 与第 9 项用途完全匹配，可直接发 | 小改可用 | 需大改或不匹配 |

**中间档的规则只用来区分 9 与 7，不另立一套 9 分标准：**

- 讲法句里**同时**出现困境与代价的具体内容（数字 / 事实 / 后果）→ **9**。
- 讲法句只出现代价、没出现困境，但提取表里两者都有 → **7**，依据写「困境与代价存在（引第 X 行），本线讲法只含代价」。
- 提取表里根本没有代价 → **6**。

判据是「讲法那句里同时有没有出现困境和代价」，不是「这条重点不重点」——不许用主观的「重点」二字裁定。

**序列类型**（依据 `references/知识库.md` 第 2 节，进入本步前必读）：
- `救赎型`：困境 → 选择 → 获得。
- `污染型`：原本好 → 变坏且未修复。
- `中性`：只是事实陈述，无明显好坏转向。

三条候选必须**走不同方向**（例如：①选择型 ②低谷型 ③认知反转型），不许是同一条的三种措辞。污染型主线**不许在第 7 步强行改写成励志结局**。

#### 5. 主线与内核裁决 — 🟠 GATE（阶段 A 主停点）

把第 3 步的缺项候选与下面三组裁决**合并成同一轮交付**。用户只答部分时，缺项在同一停点内追加一问（见下方「部分确认规则」）——这是同一停点的续问，**不算新停点**：

1. **（仅当有缺项时）核心项补问 ≤2 题**：每题 2–3 个带推荐项的候选，说明推荐理由。
2. **主线三选一**：每条附三透镜分数与打分依据、序列类型、推荐项，说明选它的代价。
3. **人物内核一句话三选一**：每条 ≤25 字、有辨识度，附「为什么这句立得住」的一句证据（回指提取表行号）。证据来源优先级：第 7 项有摘录就用第 7 项；第 7 项标缺失时，**改用第 8 项价值观摘录 + 第 5/6 项选择与结果**，并在候选后按**实际引用项**写明，例如「第 7 项缺失，依据来自第 5 行」——引用了哪行就写哪行，不许套用未实际引用的项。不单独追问第 7 项。

**用户只回答了一部分时的处理（部分确认规则）**

- 用户只答了其中一项（例如只选了内核、没选主线），**不许推定未答项后往下走**。把已确认的记录下来，未答的 🟠 项在同一轮再问一次——只问缺的那项，不重问已答的。
- **唯一例外**：用户明确说「你定 / 按推荐 / 随你」。这时才允许推定，且必须在交付时列出「推定项：主线 X（理由：____）」——理由必须写明**具体依据**（例如「与内核第 Y 条证据同源」），不许套用固定话术。
- 第 3 步的补问项未答 → 留空标「未确认」，不阻塞。
- 第 9 项用途未答 → 按「公众号长文」处理，交付时问一句要不要简介版，不阻塞。
- **主线和内核是必须拍板项，不可默认、不可推定**（除非明确授权）。

用户全部拍板（或明确授权推定）后，**把选择回填到提取表**（含第 7 项 = 选中的内核句），然后明确告诉用户「主线已锁定，接下来开始写」——这才进阶段 B。否则停住，不写正文。

### 阶段 B · 成文与验真

#### 6. 要素表 — 🔵 AUTO

按用户选定的主线，拆七格：起点 / 冲突 / 转折 / 结果 / 认知 / 可打动人的细节 / 可体现价值的部分。

每一格后面标注来源编号（对应第 2 步提取表的行号或原句）。**没有来源的格写「资料未覆盖」，不许填内容。**

#### 7. 按用途成文 — 🔵 AUTO

**先裁剪版本**（按第 5 步确认的用途，不默认两份全出）：

- 只写「公众号 / 课程页 / 朋友圈 / 融资 BP」→ 只出长文（按用途调篇幅：公众号 1500–2500 字，课程页 800–1200 字）。
- 提到「简介 / 人物介绍 / 介绍页」→ 加简介版。
- 完全没写用途 → 默认只出长文，交付时问一句「要不要简介版」。
- **用户要口播 / 短视频稿 / 朗读稿 → 不产**，如实说明本 skill 不含该能力，可另行处理。

**① 长文**

- 开头：一个具体处境，直接进场景，不铺垫、不介绍自己。
- 起点：原来处于什么状态、当时相信什么、在追求什么。
- 冲突：表面问题是什么、更深层问题是什么。
- 转折：关键事件/关键时刻/关键选择，以及当时为什么这么选。
- 结果：发生了什么变化、得到了什么、**失去了什么**、有什么数据或反馈支撑。
- 认知：真正明白了什么、和一般理解有什么不同、对别人有什么启发。
- 人物定位：用第 5 步确认的内核句收口，不另编一句。
- 结尾：一个具体可执行的动作。

序列类型必须与第 4 步标注一致：污染型不写强行救赎，中性不硬加转折。

**长文去 AI 味（四条硬规则，出现即改）**

1. **禁五段式小标题模板**（起点 / 冲突 / 转折 / 结果 / 认知）。要分节就写成有内容的短语，不许直接套这五个词——读者一眼看出是套模板的。
2. **禁过渡词堆叠**：这让我明白 / 于是 / 与此同时 / 不难发现 / 值得一提的是。删掉，用事实直接推进。
3. **禁连续三段以上「结论 + 解释」同一节奏**。长短段要错开，允许一句一段。
4. **禁排比三连**（三个同结构短句并排）。想强调就写一句长的，或者直接给事实。

**段与段之间要有承重句**。以下三类至少出现一类，否则读者会觉得在跳：时间标记（后来 / 那年 / 直到）、因果（因为 / 所以 / 可 / 而）、确认（那一刻我才知道 / 后来我才确认）。**承重句必须落在段落衔接处，不许堆在段内。**

**② 简介版**

一句话定位（≤25 字，用已确认的内核句）+ 3 个证据（每条带一个可核实的数字或具体事实）+ 一句「我能帮你做什么」。不写「资深」「专注」「致力于」这类空词。

#### 8. 验真 — 🔵 AUTO（交付前必跑，产出的是缺口清单，不是合格章）

**锁一 · 逐句回指**
扫描成文里所有含数字、时间、转折、结果、情绪判断的句子，逐句问：「这句能指回提取表的哪一行？」指认不出来的标 `待核实：____`，交用户确认或删除。**不许因为写得好看就放行。**

**锁二 · 红线扫描**
逐条扫，命中即报：

1. 替用户编造经历、关系、时间、数字。
2. 极限词与绝对化结论（最 / 第一 / 绝对 / 100% / 注定）。
3. 卖惨：渲染低谷情绪、把痛苦当卖点。
4. 悬浮金句：没有事实支撑的感悟。
5. 反本质黑话（见理论内核表）。
6. 因果越界：把「之后发生」写成「因为所以」且不给边界。
7. 人物内核空泛（「一个努力的人」「长期主义者」）。
8. **为了好听而删掉资料里的代价**（例：资料写了「失去高端客户」，成文只留「4000 人购买」）。叙事越顺越要查这条——依据见知识库第 4 节。
9. 序列类型与成文结尾不一致（污染型强行救赎 / 中性硬加转折）。
10. **段落之间没有承重句**，相邻两段靠并列硬接，读者要自己补因果。
11. **对仗口号**：两个动宾短语并列、字数相近、读着像标语（先 A 再 B / 不是 A 而是 B / 越 A 越 B）。例：「先看见人，再给方法」。长文里也要查。

**反向对照（必做）**
造一段明显编造的样本句（例：「那年我带着 30 个人连续熬了 90 天，最后做到行业第一」），喂给上面两条锁，确认它**确实报错**。另造三例：把资料里的「失去高端客户」删掉，确认第 8 条报红；把两段之间所有承重句删掉、改成并列，确认第 10 条报红；写「先看见人，再给方法」，确认第 11 条报红。造不出坏档、抓不住坏档，说明闸门是摆设，必须修。

**输出格式**
交付时附一张「验真清单」：`通过 N 项 / 待核实 N 处 / 红线命中 N 处 + 具体位置`。全绿也要写明「发现的缺口」，不许只报合格。
