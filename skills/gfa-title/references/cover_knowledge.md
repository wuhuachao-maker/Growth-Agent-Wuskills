## 一、数据速查

| 结论 | 数字 | 来源 |
|---|---|---|
| 带清晰人脸的封面 vs 无人脸 | CTR 高约 **38%** | vibbit ／ QClaw（两处独立来源，数字一致） |
| 含清晰面部表情 vs 仅产品/场景 | 高 **25%+** | 人人文库《短视频封面设计心理学》 |
| 文字封面 vs 纯图封面 | 高 **73%** | Lovart 实测（3 个账号 A/B 一个月） |
| 封面出现人物 vs 纯产品封面 | 高 **52%** | Lovart 实测 |
| 知识分享类用大字标题 vs 纯视频截图 | 高 **120%** | Lovart 实测 |
| 好物/测评用表情冲击型 vs 普通商品展示图 | 高 **85%** | Lovart 实测 |
| 大小对比（巨大物体 + 渺小人物），科技评测 | 高 **45%** | QClaw |
| 红箭头指向关键卖点，教程类 | 高 **22%** | QClaw |
| **加边框** | CTR **降 12%** | Lovart 实测（反直觉，列进避坑项） |
| 美食号「低头做饭」→「抬头微笑 + 食物」 | CTR **6% → 14%** | QClaw |

**三条最稳的推论**（本文件最该被记住的部分）：

1. **人脸是单点最强变量** —— 有脸赢一半，有表情再赢一次，**面无表情等于白放脸**。
2. **文字必须有，但必须少** —— 带文字赢过纯图，字数一多却在缩略图里糊掉；两头都要，只有"大字 + 少字"能同时满足。
3. **不要加边框** —— 唯一一条明确为负的实测项。

## 二、人脸怎么用

- **占比**：人脸占画面 **30%~40%**（vibbit）；**至少 ≥1/3**（QClaw）；竖版封面上人脸到 **50%+** 时情感传递效率最高（人人文库）。
  → 落到画幅：**9:16 竖版脸可以更大（画面 40%~55%）**；**16:9 横版脸必然变小（25%~40%）**，横版要靠"大字 + 强对比"补回注意力。
- **表情必须夸张**：惊讶 / 大笑 / 愤怒 / 疑惑。写进 prompt 时要具体到眉毛、眼睛、嘴角、头部角度。
- **明确忌讳**（vibbit 原文列出）：面无表情、侧脸、远景人像 → 这三项进负面词。
- **眼神正对镜头** —— 产生"他在对我说话"的感觉（QClaw）。对口播 / 观点类内容默认"直视镜头"。
- 用户不愿露脸 → 走 `cover.md` 风格库的 08 背影 / 09 局部出镜。

## 三、字怎么放

- **字号**：标题约占封面**高度的 1/4 ~ 1/3**（vibbit）；知识类大字约占**封面宽度的 50%**（Lovart）。
- **字数**：三个口径都要看 ——
  - 最多 **6 字**（vibbit）
  - **2~5 字**（Lovart，针对抖音推荐流）
  - 爆款封面通常 **≤12 字**（cardcrafter）
  → **综合取**：主标 **2~6 字**，整张（主标 + 副标 + 角标）**≤12 字**。
- **字体**：粗体无衬线 + **白色或黑色描边**（提升信息流里的可读性，vibbit）。
- **对比度**：浅底深字 或 深底浅字，避免相近色调。**"浅色底封面在推荐流里容易被吃掉"**（Lovart 实测）→ 9:16 优先**深底浅字**。
- **互补色对**（可直接用）：蓝+橙 ／ 红+青 ／ 黑+黄 ／ 紫+黄（vibbit）。
- **抖音底部约 20% 被交互按钮遮挡**（Lovart）；另一来源给的是上下各 15%（cardcrafter）→ 取更保守的：**底部 20% 不放任何文字**。

## 四、平台画幅与安全区

> 这是本文件里**唯一属于"平台规范"**的部分，其余都是经验值。

### 9:16 —— 1080 × 1920

| 项 | 值 | 来源 |
|---|---|---|
| 抖音推荐页 | 9:16 全屏无黑边 | cardcrafter |
| **抖音主页双列 / 合集 / 搜索结果** | **按 3:4 裁切**（安全区 ≈ 中央 1080×1440） | cardcrafter、今日头条 |
| 视频号 | 9:16；**朋友圈分享会被裁成 1:1** | 色彩韵设计 |
| 统一危险区 | 上下各 **15%**、左右各 **10%** 不放关键信息 | cardcrafter |
| 抖音底部 | 约 **20%** 被交互按钮遮挡 | Lovart |

> **硬约束**：9:16 封面的**主标题 + 人脸必须同时落在中央 3:4 框（≈1080×1440）内** —— 抖音主页、合集、搜索都按 3:4 裁。只把字放"画面中上部"不够，还要能被 3:4 裁完仍在。

### 16:9 —— 1920 × 1080

| 项 | 值 | 来源 |
|---|---|---|
| B站官方 | "建议 16:9"，1920×1080 | 压缩图、allimg |
| **B站实际显示** | 会二次裁成 **16:10 / 3:2**，需单独做一张 | 色彩韵设计、allimg |
| B站通用预览安全区 | **中央 1280×720** | 压缩图 |
| B站避让区 | 左右 10%、顶部 **15%**（UP 主动态标识） | allimg |
| B站文件上限 | **≤2MB**（超限触发强压缩，文字糊掉） | 压缩图、allimg、cn486 |
| 标题位置 | 中部 或 左上；避开**右下角时长角标** | 喵闪网 |
| YouTube | 标准 16:9，标题走英文安全区 | — |

> **硬约束**：16:9 若要发 B站，**核心元素压中央 1280×720**，顶部 15% 不放东西；同时发 YouTube / 视频号横版时统一按这个安全框写 —— 一份 prompt 通吃。

### 通用

- **缩略图测试**：压到约 **100px 宽**（喵闪网）／约 200px（旧版 gfa-cover）仍能读清主标。**这一条筛掉的封面比其它所有条加起来还多。**
- 导出 JPG/PNG；≤2MB（B站）／≤5MB（小红书）。

## 五、翻车清单

| 翻车 | 根因 | 来源 |
|---|---|---|
| 封面党：CTR 高但完播崩 | 封面承诺 ≠ 内容兑现，长期损害账号权重 | 人人文库 |
| AI 生成的图上自带文字 99% 是乱码 | 生图模型的中文字形不稳定 | 火星人教育 |
| 长标题压缩后细笔画黏连 | 平台二次压缩 | 喵闪网 |
| 模板感过强 → 审美疲劳 | 直接套现成模板 | 喵闪网 |
| 加边框 | 实测 CTR **降 12%** | Lovart |
| 浅色底封面被信息流"吃掉" | 与信息流背景对比不足 | Lovart |

> 反面提醒：**固定 Logo 位 / 固定色系 / 固定字体反而有利** —— 长期统一让老粉"一眼认出你"（喵闪网）。这不与"模板感过强"矛盾：**统一的是品牌要素，不是整套版式。**
