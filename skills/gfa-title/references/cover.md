## 〇、三条写 prompt 的铁律

1. **参考图指代写「图1 / 图2」，不复述图里所有细节** —— 复述越长，模型越容易画歪。
2. **把约束写进正向描述**（v1.7.0）—— 原来靠负面词承载的约束（手部 / 面部 / 水印 / 清晰度 / 边框）改成正向写实；**默认不输出负面词**，只在出图翻车时按第五节对症追加。
3. **具体到手在哪、谁遮挡谁** —— "她做了一个动作"这种模糊描述是出废图的第一原因。

## 一、IP 形象照怎么写（本 skill 的核心输入）

用户上传的形象照**固定作为图1**，第 2 张起才是素材图。

**写法（三段式，每套 prompt 都要有）**：

```
参考图1 的形象，保持面部特征一致，[出镜程度：肩部以上特写 / 半身 / 只露手 / 背对镜头]。
```

**只锁"不可变特征"，不复述长相** —— 这是本 skill 的硬规则：

- ✅ 该写的：**发型**（长度 / 是否露额头 / 有无刘海）、**眼镜**（有无、框型）、**标志性服装**（常穿的颜色与款式）、**习惯构图**（偏左偏右 / 喜不喜欢手部入画）。
- ❌ 不该写的：脸型、五官细节、肤色描述 —— 这些交给参考图，文字复述只会覆盖掉参考图、把脸画成另一个人。

**形象照质量前置检查（🔵 自动，命中才提醒）**：正脸清晰、无遮挡、光线均匀、分辨率 ≥ 1000px。四项任一不满足 → 在交付时提醒"这张参考图保真度会打折，建议换一张正脸清晰的"，但**不要因此中断流程**。

**降级路径**：用户没上传形象照，或所用模型不支持参考图 →
- 照常产出 prompt，但把首句改成 `参考图1 的形象` 并在交付时明确写一句：**"把这张提示词和图1（你的 IP 形象照）一起发给生图工具"**；
- 若模型完全不支持参考图 → 明说"这个模型保持不了人脸一致性，建议换支持参考图的（如 nano-banana-pro / 即梦 / MJ --cref）"，**不要静默用文字描述冒充**。

## 二、构图风格库（10 套）

**风格决策表**（先查表定首选，再给 2 个备选；不要在 10 套里让用户拍脑袋）：

| 内容特征 | 首选风格 | 凭什么 |
|---|---|---|
| 纯观点 / 金句 / 认知冲击 | **10 正面对视** 或 **05 极简留白** | 无素材可看，只能靠文字与眼神撑 |
| 情绪强 / 震惊 / 反差 | **01 深色渐变** | 高对比最强冲击，配合情绪峰值 |
| 个人故事 / 自述 | **07 人物侧置留白** | 留白给情绪，人物不逼视 |
| 励志 / 成长 / 启发 / 心境 | **08 背影** | 制造代入感，不给答案 |
| 干货清单 / 步骤 / 方法论 | **02 纯色扁平** 或 **09 局部出镜** | 信息清爽优先，不抢戏 |
| 有 UI 截图 / 产品图 / 工具教程 | **03 产品主视觉** | 素材本身就是主体，人物退为引导 |
| 前后对比 / 好坏对比 / 新旧对比 | **04 对比卡片** | 对比需要画面里存在"两张卡"的物理位置 |
| 素材 ≥3 张（多截图叠加） | **06 海报拼贴** | 需要分层容纳，单主体塞不下 |

**反向排除规则（先排除，再推荐）**：

- 元素 >5 个 → 不用 05 极简留白
- 没有任何素材图 → 不用 03 产品主视觉、06 海报拼贴
- 标题 >8 字 → 不用 04 对比卡片（画面会被字占满）
- 用户不想露脸 → 走 08 背影 或 09 局部出镜
- **16:9 横版 → 优先 07 人物侧置留白 / 02 纯色扁平 / 03 产品主视觉**（横版留白天然抗裁，人脸在横版里天然偏小，靠版式补）
- **9:16 竖版 → 优先 10 正面对视 / 01 深色渐变 / 08 背影**（竖版脸能放大，人脸优势最大化）

---

### 01 深色渐变 ｜ 人物居中，大字压在身后，高对比强冲击

- **人物**：只要半身，居中；标题超大字压在人物背后，被轻微遮挡做层次
- **背景**：深色渐变（深藏青 → 暗红这类），高饱和
- **平台**：9:16 人物可占 55%~70%；16:9 只画到胸口以上，字压中央 1280×720 框
- **翻车**：渐变过艳显廉价；大字被遮到读不出（**遮挡只允许压住字边缘 1/5 以内**）

### 02 纯色扁平 ｜ 人物抠图感，纯色背景，干净清爽

- **人物**：抠图边缘利落无毛边；标题横排，与背景高对比
- **背景**：单一纯色，**完全平整无渐变无晕影无肌理**
- **平台**：**横版（16:9）最适配** —— 纯色横向延展天然抗裁；9:16 也能用，但要让纯色区足够大
- **翻车**：模型总爱加渐变晕影，必须正负双向强调；纯色别选中间灰

### 03 产品主视觉 ｜ UI 截图 / 产品图占主体，人物做引导手势

- **人物**：只做托举、指向手势，不做主体；素材占 30%~65%
- **参考图**：写"保持界面结构与文字清晰可辨，不要重新绘制界面"
- **平台**：**16:9 是主场**（两张截图左右并排）；9:16 可上下叠放
- **翻车**：模型把 UI 重画（最高频）；素材太小缩略图看不出是什么

### 04 对比卡片 ｜ 人物手持两张对比卡片

- **两张卡**：一近一远，透视比例至少 2:1；写清各自代表什么
- **平台**：9:16 上下错开；16:9 左右并排
- **翻车**：**标题超过 8 字就该换风格**；卡上小字会变乱码

### 05 极简留白 ｜ 大面积留白，文字是唯一焦点

- **留白 ≥60%**；标题字号极大（占封面高度 1/3 以上）；元素 ≤3 个
- **平台**：9:16 是主场；16:9 宽幅下留白会变成"空"，建议换风格
- **翻车**：模型总把留白填满（正向写死留白比例 + 「画面仅由标题与背景构成」）；字不够大就彻底失败

### 06 海报拼贴 ｜ 多张素材叠加，分层有纵深

- **至少三层**：前景 / 中景 / 后景，写清谁遮挡谁，后景适度模糊
- **平台**：9:16 主场；16:9 高度不够，**层数压到 2 层**，否则挤成一条
- **翻车**：没写清遮挡关系就糊成一坨；素材 <3 张别用；卡片过度倾斜像废纸

### 07 人物侧置留白 ｜ 人物偏一侧占小比例，另一侧全给标题

- **人物占 25%~40%**，偏左或偏右；标题在留白区；表情克制
- **平台**：**16:9 表现最好**（人物居左 30%，右侧 70% 给标题），9:16 要压缩到人物占 25%~35%
- **翻车**：人物站到中间去（分区失效）；标题塞太满（留白的本质是敢空）

### 08 背影 ｜ 人物背对镜头，制造代入感

- 看不到脸，**跳过表情项**；视线有明确朝向；前方留给场景或目标物
- **平台**：9:16 天然适配（背影竖向延展）
- **翻车**：模型给画出正脸（正向反复写「背对镜头、看不到五官」，仍不行才按第五节对症加负面词）；背影轮廓要与背景分离

### 09 局部出镜 ｜ 只露手 / 半脸 / 侧脸，产品或文字是主角

- 人物只出现局部；主体产品要描述精细
- **额外价值**：**天然规避"脸不像"和"手畸形"两个高频翻车点**
- **翻车**：手部仍有畸形风险（正向写「五指清晰自然、关节比例正常」；仍不好就换手部不入画的构图）；别描述成完全没有人物

### 10 正面对视 ｜ 直视镜头，文字环绕脸部四周

- 人物肩部以上特写，居中直视；文字绕开面部，**不遮挡五官**
- **平台**：**9:16 的最强项** —— 脸大、眼神冲击直接
- **翻车**：文字压到脸上；人脸占画面最大，最暴露"像不像"的问题

### 三种强调版本（与构图风格正交的另一根轴）

10 套风格决定「怎么排」，三种强调版本决定「谁是主角」—— **后者对结果影响更大**，所以默认三版都出。

| 版本 | 画面主体 | 9:16 人脸占比 | 16:9 人脸占比 | 最适合 |
|---|---|---|---|---|
| **人物主导** | IP 形象的脸与表情 | 40%~55% | 25%~40% | 观点 / 情绪 / 自述类，认脸涨粉 |
| **文字主导** | 大字本身，人退到边角 | 0%~20% | 0%~15% | 干货 / 金句 / 清单，要点必须被扫读 |
| **场景主导** | 与主题有关的物件与环境 | 0%（可不出现人物） | 0% | 有具象物的主题；也是规避「脸不像」「手畸形」的兜底版 |

改写要点（同一份内容，三版只换三处）：

1. **主体句**：人物主导 → 写表情与手的动作；文字主导 → 人物压到左下角并缩到 20% 以内，或直接删掉人物句；场景主导 → 换成「俯拍桌面 + 物件描述」，删掉所有人物句。
2. **文字占比**：人物主导 → 主标常规大；文字主导 → 主标拉到**占画面高 1/3 以上**（9:16）或**占宽一半以上**（16:9）；场景主导 → 主标常规大。
3. **背景**：人物主导 → 渐变或场景；文字主导 → 大面积留白，写死「画面仅由标题、角标与背景构成」；场景主导 → 桌面材质。

⚠️ **三版的封面标题文案与视觉基调必须一致** —— 换的是载体，不是承诺。三版说的事不一样，等于三个内容。

## 三、提示词骨架（两套画幅各一份）

### 9:16 竖版（1080 × 1920）

```
9:16 竖版构图，1080×1920。

参考图1 的形象，保持面部特征一致，只要肩部以上特写。
[夸张表情：具体到眉毛/眼睛/嘴角/头部角度]，人物位于画面中央，眼神直视镜头，
[身体位置]，[手的具体动作或在做什么]，
[主视觉元素的具体描述：形状 / 上面有什么内容 / 大小比例 / 动态或静态]，
[前景 / 中景 / 后景各是什么，谁遮挡谁]

巨大的中文大字"[主标]"位于画面中上部，超粗无衬线黑体，白色字＋深色描边，
笔画完整清晰，[被某元素边缘轻微遮挡形成层次，遮挡不超过字高的五分之一]；
副标题"[副标]"字号约为主标的一半，位于主标下方，[颜色]

背景：[具体色调]，[深底浅字 / 浅底深字]，柔和过渡

版式要求：主标题与人物面部必须完整落在画面中央的 3:4 安全框内（约 1080×1440），
因为抖音主页双列、合集与搜索结果都会按 3:4 裁切；
画面底部约 20% 区域只保留背景，不放任何文字与关键元素；
画面四边上下各留 15%、左右各留 10% 不放关键信息

[点缀元素：数量极少，只做点缀]
```

### 16:9 横版（1920 × 1080）

```
16:9 横版构图，1920×1080。

参考图1 的形象，保持面部特征一致，只要半身，人物位于画面[左/右]侧，占画面约 28%，
姿态克制，眼神看向[标题所在的留白区]。

巨大的中文大字"[主标]"横排位于画面[右/左]侧留白区域，超粗黑体，[深墨色/白色]，单行排布；
副标题"[副标]"字号约为主标的一半，位于主标下方，[中灰色]

背景：[具体色调]，大面积留白

版式要求：主标题与人物面部必须完整落在画面中央 1280×720 的预览安全框内；
画面左右两端各 10%、顶部 15% 只保留背景，不放任何文字与关键元素
（B站会二次裁成 16:10/3:2，且顶部有 UP 主动态标识）

[点缀元素：数量极少，只做点缀]
```

## 五、负面词（按需排障工具，默认不输出）

**v1.7.0 起不再默认输出负面词。** 现代生图模型（Nano Banana Pro / 即梦 / GPT-Image 级别）稳定性已足够，负面词多数情况是噪音，还会挤占提示词的注意力预算。

**正确做法**：把原来靠负面词承载的约束**改写进正向描述** ——

| 原来写负面词 | 现在写正向 |
|---|---|
| 不要畸形的手 / 多余指头 | 五指自然张开、关节比例正常、指尖清晰 |
| 不要面无表情 / 侧脸 | 表情夸张到眉峰收紧、嘴角下压、眼神直视镜头 |
| 不要模糊 / 低分辨率 | 主体锐利清晰、边缘干净 |
| 不要边框 / 相框 | 画面满幅，不出现任何画框结构 |
| 不要多余水印 / logo | 画面内只出现指定的那几行文字，其余区域干净纯色 |
| 不要填满留白（05） | 留白占画面 60% 以上，画面仅由标题与背景构成 |

**只在出图确实翻车时，按症状对症追加**（一次加一条，不要一次糊一大段）：

| 症状 | 对症负面词 |
|---|---|
| 中文写错字 / 多字漏字 | 错别字、多字漏字、无意义的伪文字、乱码 |
| 画面里冒出额外文字 | 多余的文字、水印、logo、签名、二维码、网址 |
| 手部畸形 | 畸形的双手、多余的指头、错位的手指 |
| 人脸不像 / 面无表情 | 侧脸、远景人像、面无表情、面部扭曲不对称、五官变形 |
| 出现了画框 | 边框、相框、描边相框 |
| 背景被填满（留白类） | 背景图案、纹理、装饰线条 |
| 画面发糊 | 模糊、噪点、压缩痕迹、低分辨率 |
| 01 深色渐变专症 | 文字被遮挡超过五分之一；渐变过艳发廉价 |
| 02 纯色扁平专症 | 背景的渐变、晕影、暗角、颗粒、肌理 |
| 03 产品主视觉专症 | 重新绘制或改写参考图中的界面内容；界面文字变乱码 |
| 08 背影专症 | 正面脸部、人物回头看镜头 |
| 09 局部出镜专症 | 露出的完整人脸、多余指头 |
| 10 正面对视专症 | 文字压到或遮挡五官；墨镜、口罩 |

⚠️ 老规矩不变：**负面词不能替代正向描述** —— 写"不要模糊"不如写"主体锐利清晰"。**翻车先改正向，正向改完还不行才加负面。**
⚠️ **中文字是唯一例外**：错字既不是正向描述能保证的，也不是负面词能解决的，只能靠压字数 + 出图后逐字回读 + 必要时后期补字。

## 六、出图后逐字回读校验（8 项 · 闭环关键）

出图后**必须把生成的图重新读一遍**，逐项过。这一步不能跳。

| # | 检查项 | 不通过怎么办 |
|---|---|---|
| 1 | **文字逐字比对**：画面文字 vs 主标原文，一字不差（盯形近替换：已/己、未/末） | 定位是哪个字错 → 该字拆开单独强调，或换笔画更少的同义字 → 重跑 |
| 2 | **人脸与参考图五官是否一致** | 检查参考图指代是否写对；提高参考图描述权重 |
| 3 | **手部是否畸形**（多指/少指/扭曲） | 手部描述加具体约束，或改用 07 侧置 / 09 局部（手部不入画） |
| 4 | **标题是否被遮挡到不可读** | 降低遮挡程度，或写明"压在被遮挡元素之后但保持可读" |
| 5 | **关键元素是否落在安全区**（9:16：中央 3:4 框 + 底部 20% 无字；16:9：中央 1280×720） | 调整位置重跑 |
| 6 | **是否出现模型自造的文字/水印/乱码** | 先改正向描述（明确「画面内只出现指定文字」）；仍不行再按第五节对症加负面词；工具自带水印负面词管不了，必须后期裁掉 |
| 7 | **实际像素与比例** | 重新出图并锁定比例参数（比例对 ≠ 尺寸对） |
| 8 | **缩略图测试**：压到约 100px 宽，主标还读得清吗 | 字号加大、字数减少、对比度提高 |

**同一问题连续两次不过就不是运气问题**，改提示词而不是原样重跑：

- 中文总写错 → 减字 → 换字 → 拆分层 → **后期用编辑工具补字**（成熟账号的常规做法）
- 手部总畸形 → 换成手部不入画的构图
- 界面被重画 → 该模型保真能力弱，改用"后期贴截图"
- 画面总显乱 → 减元素数量，或换更简洁的风格

**看不到图时**：明确告诉用户"我看不到刚生成的这张图，请把它发回来我来校验"，然后停下等。**不要跳过校验，不要假装已经检查过。**

## 七、多模型能力差异（出图前先确认）

| 能力 | 为什么会翻车 | 应对 |
|---|---|---|
| **中文文字渲染** | 各模型差异极大，长标题错字率高 | 出图前先跑一次小测试（只生成 4 个中文大字，看有没有写错）；长标题不稳就"只出画面、标题后期加" |
| **多参考图** | 部分模型只吃 1 张，或第 1 张权重过高 | 图1 固定形象照，图2 起为素材；确认模型支持多图 |
| **人脸一致性** | 不支持参考图的模型完全做不到 | 换支持参考图的工具，别硬凑 |
| **画幅比例** | 说 9:16 出成 1:1 | 提示词首行写死比例 + 分辨率，生成后核对实际像素 |
| **自带水印** | 负面词管不了 | 后期裁掉或覆盖；注意水印常落右下角——正是平台角标位置 |
