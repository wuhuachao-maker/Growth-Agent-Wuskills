# 爆款标题知识库（小红书 / 公众号 / 抖音）

> 本文件是 `gfa-title` 的「知识充分」支柱。生成标题前必须内化以下内容：
> 六大心理驱动力 → 三平台流量机制差异 → 平台公式库 → 公式选择决策 → 红线 → 自检维度 → 缺口质量阶梯(7) → 扒源方法(8) → 具体性硬规则(9)。

---

## 0. 总原则

标题唯一的工作，是让用户在那 **0.3 秒** 里「想点」而不是「划走」。

- 好标题不是让人「看懂」，是让人「想点」。
- 所有公式都服务于第 1 节的六大心理驱动力。
- 同一个选题，不同标题的流量可以差 **10 倍**（抖音实测）或决定一篇公众号能否刷屏。
- 现代标题还承担两个延伸职责：**被搜索系统搜到（SEO）** 与 **被 AI 引擎引用（GEO）**——两者在阶段 3 单独处理（见第 10、11 节）。

## 1. 六大心理驱动力（跨平台通用，标题的发动机）

| # | 驱动力 | 原理 | 标题手法 |
|---|--------|------|----------|
| 1 | **好奇心缺口** (Information Gap, Lowenstein) | 人意识到「已知」与「想知」之间有缝，就会痒，迫切想补 | 悬念、留白、省略号、话讲一半 |
| 2 | **损失厌恶** (Loss Aversion) | 怕失去 > 想获得。「不看的损失」比「看了的收获」更驱动点击 | 「必须 / 千万 / 刚刚 / 别错过」 |
| 3 | **身份对号入座** (Social Identity) | 人对「跟我有关」的事物本能感兴趣 | 年龄 / 性别 / 职业 / 地区 / 星座 / 人群标签 |
| 4 | **认知冲突 / 反差** | 常识被颠覆，大脑必须去验证 | 「越努力越废」「月薪 5k→3w」 |
| 5 | **情绪唤醒** (Emotional Arousal) | 共鸣 / 愤怒 / 爽 / 治愈，情绪越强越易互动 | 「说的就是我」「别再偷看我朋友圈」 |
| 6 | **实用 / 信息差** (Utility & Info Gap) | 让人觉得「收藏了就有用 / 别人不知道我知道」 | 清单体、干货、内幕、揭秘 |

> 强标题通常**叠加 2–3 个驱动力**，例如「数字 + 身份 + 损失厌恶」。

## 2. 三平台流量机制差异（决定标题长相的根本）

| 维度 | 小红书 | 公众号 | 抖音 |
|------|--------|--------|------|
| **标题作用** | 搜索入口 + 封面搭档，决定点击 | 决定打开率 **+ 朋友圈转发率**（转发才是刷屏核心） | 决定前 3 秒停留，配合视频 hook |
| **最优长度** | 15–20 字（超 20 手机显示不全） | ≤ 25–30 字（64 字符上限，转发会折叠） | 短，常 ≤ 15 字 + emoji，配合口播 |
| **核心驱动** | 搜索可发现性 + 种草情绪 | 朋友圈「人设安全」+ 社交货币 | 完播率 + 评论区互动引导 |
| **用户心态** | 主动搜 / 逛，求解决方案 | 浅阅读刷，怕标题让人设翻车 | 被动刷，前 3 秒定生死 |
| **可否「虚」** | 不可，货不对板掉收藏 | 不可，伤预期会取关 | 可夸张钩子，但不可骗 |

**关键推论：**
- 小红书标题必须**天然含 2–3 个高搜索量词**（如「职场新人 / 周报 / 打工人」），且选题间去重——搜索流量近半来自搜索。
- 公众号标题必须让**转发者人设安全**：「老子再也不想加班了」这种会让读者不敢转；「离开北京后，我开始怀念北京了」才适合朋友圈打开。
- 抖音标题是**钩子 + 互动引导**，常配「你中几个 / 评论区告诉我」提升评论率，从而撬动推荐。

## 3. 平台公式库

### 3.1 小红书（5 公式，源自 100+ 爆款分析）

| 公式 | 结构 | 案例 |
|------|------|------|
| **F1 数字 + 悬念** | X 个[方法]，第 Y 个最关键 | 「5 个让老板刮目相看的习惯，第 3 个最重要」 |
| **F2 身份 + 痛点 + 方案** | [人群] + [痛点] + [怎么解决] | 「新手妈妈最常犯 3 个喂养错误，你中几个？」 |
| **F3 对比反差** | [之前] vs [之后] | 「从月薪 5k 到 3w，我做了这 3 件事」 |
| **F4 情绪共鸣** | 说读者不敢说的话 | 「「普通人」这三个字，毁了多少人的梦想」 |
| **F5 实用清单体** | N 个 + 场景 + 好处 | 「10 个提升效率的 App，最后一个太好用」 |

- **搜索可发现性（默认开启）**：每条标题天然含 2–3 高搜索量词，选题之间去重覆盖不同搜索意图。
- **避坑**：不标题党（承诺≈内容）、不文艺抽象、控制在 15–20 字。

### 3.2 公众号（1 底层公式 + 9 套路 + 5 细节）

**底层公式**：`阅读量 = 粉丝打开 + 朋友圈分享打开`。转发率才是刷屏核心 → 标题必须让转发者「人设安全」。

**9 套路（可叠加组合）：**
1. **关键词吸睛** — 对号入座（年龄/性别/职业）/ 升维词（「偷看」→「视奸」）/ 抱大腿（名人·热点·KOL）
2. **冲突反差** — 数字对比（月薪 6k vs 2w）/ 认知矛盾（「越努力，死得越快」）
3. **提问式** — 痛点疑问（「为什么男性不再追求女性？」）/ 自问自答（「设计 logo 难吗？3 分钟搞定」）
4. **悬念式** — 省略号留白（「老板跪求我别辞职……」）/ 场景窥探（「考研失败的年轻人，后来都怎样了」）
5. **场景式** — 具体细节场景（「女朋友解锁了我的手机」）
6. **经验分享式** — 透露干货（「短视频创意素材 5 步走」）
7. **情绪式** — 煽动情绪（「有事直说，别问在吗」）
8. **强调式（损失厌恶）** — 「必须 / 千万 / 刚刚 / 突发」
9. **直言式** — 新闻 / 促销直给（「iOS14.4 正式版发布」）

**5 细节：**
- 多**具体数字**（「3000 个大学生 / 7 条」> 虚词「无数 / 最全」）
- 用**符号**增强（`！？……「」` 增加辨识度与悬念）
- **不玩文字游戏**（把读者当初中生，简单直白）
- 建**标题库**，日常积累同行爆款
- 长度 ≤ 25–30 字，避免转发折叠

### 3.3 抖音（5 钩子公式，源自 500+ 百万播放）

| 钩子 | 公式 | 反例 → 正例 |
|------|------|-------------|
| **H1 悬念** | 已知信息 + 未知缺口 | ❌「今天教做红烧肉」→ ✅「红烧肉这样做肉香多一倍——关键不在酱油」 |
| **H2 冲突** | 常识 / 预期 vs 反常识 / 反转 | ❌「如何提高互动率」→ ✅「为什么越互动粉丝越少？90% 做错了」 |
| **H3 数字** | 具体数字 + 结果 / 步骤 | ❌「快速涨粉方法」→ ✅「3 天涨粉 5000，我只做了这 4 件事」 |
| **H4 反常识** | 挑战认知 + 证据暗示 | ❌「如何做好运营」→ ✅「你做的所有运营，可能都是无效努力」 |
| **H5 情感** | 情感锚点 + 身份认同 | ❌「新手常见错误」→ ✅「做了半年才明白：没人告诉你这些坑」 |

- 标题常配**互动钩子**引导评论（「你中几个 / 第 5 个最好用」），提升评论率撬动推荐。
- 播放量可差 10 倍，标题即前 3 秒的延伸。

## 5. 红线（生成时必须规避）

1. **不标题党**：标题承诺 ≈ 内容，不货不对板（否则掉粉 / 限流）。
2. **不碰极限词**：最 / 第一 / 国家级 / 绝对 / 100% —— 小红书 2025 严打，直接限流。
3. **小红书 2025 新规**：对比图需标「原相机 + 时间」；AI 创作需声明；短笔记 ≥ 100 字禁搬运；站外导流全面封禁。
4. **不侵权**：不冒用名人 / 品牌背书（除非真实）。
5. **不低质洗稿 / 拼凑**。
6. **抖音**：不诱导违规互动，不碰敏感。
7. **公众号**：标题别让转发者人设翻车（见 §2 推论）。

## 6. 自检评分维度（供 KPI 使用）

| 维度 | 评估什么 |
|------|----------|

## 7. 好奇心缺口质量阶梯（强缺口 vs 弱缺口）

好奇心缺口（Loewenstein）是爆款第一驱动力，但"有缺口"≠"好缺口"。差别在**承诺是否具体**。

| 等级 | 特征 | 弱缺口（禁用） | 强缺口（必学） |
|------|------|----------------|----------------|
| 弱 | 含糊吊胃口，不承诺答案 | "做对了什么" / "一个问题" / "真相" | — |
| 中 | 有方向但抽象 | "比粉丝数更重要的东西" | "比粉丝数更值钱的是客户密度" |
| 强 | 承诺一个具体、可验证的答案 | — | "9万粉年销1亿，每个粉丝给你1100块" |

**强缺口三要素**：① 给一个具体数字/事实作锚；② 暗示"看完你就能知道答案"；③ 答案反直觉或反常识。
**自检**：若把标题的"悬念部分"换成"具体内容"后反而更无聊，说明原缺口是弱缺口，须重写。

## 8. 扒源提取方法（标题有"刺点"的前提）

生成前若用户给了原文，先扒三层，标题必须围绕它们建造：

1. **Shock specifics（3–5 个）**：原文里最反常识、最具体的数字或事实。
   - 例（羊绒案例）：9万粉年销1亿 / 每个粉丝贡献≈1100元 / 复购70% / 2024.4→2025破亿 / 写了几百条笔记。
2. **金句/狠话（1–2 句）**：原文最扎心、最像"标题"的话，直接挪用或微调。
   - 例：「客户在第100次接触你时才下单」 / 「你发10条就放弃，她发了几百条才破亿」。
3. **核心反差点（1 个）**：常识 vs 真相。
   - 例：常识"大号才能赚钱" vs 真相"粉丝数没用，客户密度才值钱"。

无原文时：用行业公开数据补足，但标注「推测」，不编造品牌/人名/精确数字。

## 9. 具体性硬规则 + 禁用虚词清单

标题的"实锤感"来自 specifics，不是形容词。

**必须满足**：每条标题含 ≥1 个可验证 specifics（具体数字 / 罕见事实 / 专有名词 / 原文金句）。
**禁用虚词**（出现且不说清所指即改写）：
- 占位类：一个问题 / 一个转变 / 一个指标 / 一个方法 / 这件事 / 这个坑
- 空洞类：很重要 / 很关键 / 做对了什么 / 真相 / 秘密 / 内幕 / 原因（不揭晓）
- 例外：若同句/同标题立即揭晓具体所指（如"比粉丝数更值钱的，是客户密度"），可用。

**好标题 vs 模板标题对照：**

| 模板感（差） | 具体感（好） |
|--------------|--------------|
| 做内容获客的IP，先问自己一个问题 | 9万粉年卖1亿，算下来每个粉丝给你1100块 |
| 为什么你学会了一切却什么都没学会 | 你发10条笔记就放弃，她发了几百条才破亿 |
| 比"低粉高销"更值钱的，是这个词 | 客户第100次刷到你才下单，你停在了第10次 |

## 10. SEO 关键词分层法（站内 / 搜索引擎可发现性）

标题被"搜到"靠的是关键词与搜索意图的精准匹配。三步法：

### 10.1 三层关键词模型（按价值与竞争度分层）

| 层 | 类型 | 作用 | 示例（职场周报） |
|----|------|------|------------------|
| 核心词 | 1 个，最高频、最泛 | 必前置（标题前 6–8 字命中），决定流量底盘 | 周报 |
| 精准长尾 | 1–2 个，低竞争高意图 | 蓝海优先，覆盖具体 query | 职场新人周报模板 / 周报怎么写老板满意 |
| 人群/场景 | 辅助 | 增强身份对号 + 搜索匹配 | 职场新人 / 转正期 / 互联网 |

- **核心词前置原则**：小红书 / 抖音标题核心词尽量出现在前半句；公众号可中置（受转发人设约束时让位给人设安全）。
- **蓝海优先**：长尾词选"搜索量中等但竞争低"的具体问句式，避开红海大词。

### 10.2 搜索意图匹配

| 意图 | 用户心态 | 标题对应结构 |
|------|----------|--------------|
| 信息型 | "怎么办 / 怎么选" | 教程 / 清单 / 攻略（含步骤、数字） |
| 交易型 | "买哪个 / 推荐" | 测评 / 对比 / 清单（含品牌 / 型号实体） |
| 导航型 | 找特定品牌 / 人 | 品牌 / 人名直接入标题 |

### 10.3 三平台取词差异

- **小红书**：站内搜索为主，用户爱搜"XX 推荐 / XX 教程 / XX 避雷"，长尾问句多。
- **抖音**：视频搜索关键词 + 话题词（#），口语化、动作化（"如何 / 3 分钟"）。
- **公众号（微信搜一搜）**：偏文章 / 干货，长词 + 问题式（"为什么 / 怎么理解"）。

### 10.4 选题去重覆盖

同一主题的 10 条标题，关键词组合应覆盖不同 query，避免自我内耗（如同时用"周报模板"与"周报结构"，不重复堆"周报"）。

## 11. GEO 生成式引擎优化法（生成式引擎可引用性）

GEO = Generative Engine Optimization：让标题 / 内容被 AI 搜索（豆包 / 元宝 / DeepSeek / 夸克 AI / Kimi / AI 概览等）理解、抽取、引用。AI 引擎不"搜关键词排名"，而是"判断哪段最像答案并摘录"。

### 11.1 标题即答案

好 GEO 标题 = 一个明确问句的紧凑答案。生成时先写下"用户会怎么问 AI"，再让标题直接回应：

| 用户问句（query） | GEO 友好标题 |
|-------------------|--------------|
| 周报怎么写老板才满意？ | 周报怎么写老板秒批？3 个结构 + 1 个模板直接用 |
| 小红书新手怎么起号？ | 小红书起号 7 天计划：第 3 天发什么最关键 |

### 11.2 实体清晰度（GEO 第一铁律）

- 主体必须写清**是什么**：品牌 / 人名 / 工具 / 数字 / 年份 / 型号直接出现。
- 模糊代词是 GEO 大忌："这个方法 / 这款产品 / 那件事"——AI 无法稳定引用。
- 与 §9 具体性规则同源：实体即 specifics。

### 11.3 可引用性三要素

1. **明确结论**：标题本身给出立场 / 答案，而非只抛问题。
2. **可验证数据**：带数字 / 事实，让 AI 摘录时有"锚点"。
3. **结构化线索**：N 个 / 步骤 / 对比 / 清单，便于 AI 拆条引用。

### 11.4 GEO 问句库（生成时反向映射）

为每条 GEO 友好标题附一个可反查问句，确保"标题 = 答案"成立。常见问句骨架：
- 怎么办类："XX 怎么 / 如何 + 动作"
- 为什么类："为什么 + 现象"
- 选哪个类："XX 和 XX 哪个好 / 怎么选"
- 是什么类："XX 是什么 / 值得吗"

### 11.5 SEO 与 GEO 的交集与分工

- **交集**：都爱具体实体和数字（§9 地基）。
- **分工**：SEO 求"匹配关键词被搜到"；GEO 求"回答一个问题被引用"。一条好标题应**既含对的词，又是一个能被引用的答案**。
