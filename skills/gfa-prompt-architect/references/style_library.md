# 风格词典与爆款元素库（可复用）

用于「文案 / 内容 / 互动类」Prompt。当任务涉及语气、风格、“吸引人”的表达或“被搜到 / 被看到”时，
**不要写“用金枪大叔风格”这种黑话就完事**，也不要只堆情绪——把风格翻译成 AI 能执行的具体行为，并默认带上「搜索可发现性」意识（见第四节）。
下面词典与规则可直接引用或裁剪。

## 一、风格词典（风格 → 可执行行为）

| 风格关键词 | AI 应执行的具体行为 |
|-----------|---------------------|
| 金枪大叔风格 | 挑衅式开局；抛反常识观点；短句、狠话；多用“你”直击痛点；不讨好 |
| 专业化风格 | 数据/术语驱动；结论先行；克制情绪；引用可验证来源；结构严谨 |
| 标题党风格 | 悬念/数字/冲突开头；制造好奇缺口；承诺明确收益；控制夸张程度 |
| 口语化风格 | 像朋友聊天；短句为主；适当口语词（“其实”“说白了”）；少用书面连词 |
| 故事化风格 | 以具体人物/场景切入；有起承转合；用细节代替抽象 |
| 权威感风格 | 第三人称客观陈述；引用规则/研究；措辞稳重不煽动 |
| 温暖陪伴风格 | 共情先行（“我知道你…）；鼓励性收尾；少用命令式 |

> 用法：在 Prompt 的【风格与语气】段写“采用{{风格}}：{{对应行为}}”，把词典内联进去，
> 或写“参考 prompt-architect/references/style_library.md 的词典”。

## 二、爆款元素库（开头/正文可叠加的元素）

每条都是可点选的“钩子类型”，建议开头叠加 ≥3 条：

| 元素 | 一句话定义 | 示例钩子 |
|------|-----------|----------|
| 痛点前置 | 先戳中读者最烦的事 | “你是不是也每天忙到深夜，却越忙越穷？” |
| 反常识 | 推翻一个普遍认知 | “越努力越失败，这话在XX领域是真的。” |
| 权威背书 | 借专家/数据抬 credibility | “哈佛研究跟踪了10年，结论出乎意料。” |
| 场景代入 | 让读者“看见”自己 | “周五晚上11点，你瘫在沙发上刷手机…” |
| 数字冲击 | 用具体数字制造反差 | “3个月，0成本，涨了2万粉。” |
| 情绪共鸣 | 说出读者憋着的话 | “没人告诉过你：焦虑不是你的错。” |
| 稀缺紧迫 | 制造错过感 | “这个方法，明年大概率就失效了。” |
| 身份认同 | 用“我们/这类人”绑定 | “真正吃过苦的人，都懂这句话。” |
| 对比反差 | 前后/正负强烈对照 | “别人花5万学的，我免费讲给你。” |
| 故事钩子 | 用未完故事勾住 | “我朋友去年做了个决定，今年换了辆车。” |

## 三、使用约定

- **选元素**：写 Prompt 时写明“开头叠加 ≥3 个爆款元素，并从元素库指定类型（如：痛点前置+反常识+数字冲击）”。
- **控风险**：标题党/数字冲击类元素必须配【红线】——“数字可验证/可替换，不虚构收益”。
- **可扩展**：用户有自家风格词时，在词典后追加一行映射即可，不要让它停留在“AI 应该懂”的假设。

## 四、搜索可发现性（内容类 Prompt 必带，默认开启）

内容平台的流量很大来自搜索（小红书近半、公众号 / 知乎 / 抖音也高）。只堆“情绪 / 爆款元素”而忽略“能被搜到”，是内容类 prompt 最常见的隐性失效——点子再好，没人搜得到也白搭。

**写内容类 Prompt 时，默认加入以下要求（除非用户明确不要）：**

1. **关键词工程化**：每个选题 / 标题须天然含 2–3 个高搜索量关键词，优先长尾词（如“职场新人周报模板”优于“模板”）。
2. **去重覆盖**：保证选题 / 角度之间不撞车，覆盖不同搜索意图，而非同一卖点换皮。
3. **字段化**：在输出骨架中为每个选题增加「搜索关键词（2–3 个）」字段。
4. **可考核**：在 KPI 增加「搜索可发现性」维度（标题是否含可搜词、是否与其他选题重复）。

> 用法：在 Prompt 的【知识库】写“参考 prompt-architect/references/style_library.md 第四节：搜索可发现性”；
> 在【执行结构】为选题增加「搜索关键词」字段；在【KPI】增加「搜索可发现性」维度。

> 注意：关键词须真实可搜、贴合赛道，不得为堆词硬塞无关热词（配【红线】约束）。
