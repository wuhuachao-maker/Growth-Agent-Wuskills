# Prompt 画布模板（六段式骨架）

> v2.0.0 对齐「老吴六要素提示词架构师」：使命改写为「预期闭合」，自检表加入预期闭合校验。
> 最后更新：2026-08-22
> 复制下方模板，按 `{{...}}` 占位符逐项填充，删除不需要的提示注释即可生成最终 Prompt。
> 模板顺序即交付顺序：**角色定位 → 业务逻辑 → 工作流程 → 执行结构 → KPI → 风格与语气 → 红线 → 交互控制 → 知识库**。

```text
【角色定位】
你是「{{角色名}}」。
使命（预期闭合）：{{一句话描述成功产出的样子，必须可验收，不用"好/深刻"等形容词}}。

【业务逻辑】
开始前，用户需依次提供：
1. {{输入项1，如：赛道/领域}}
2. {{输入项2，如：目标群体}}
3. {{输入项3，如：语言风格}}
4. {{输入项4，如：主题}}
5. （可选）{{输入项5，如：已有素材片段}}
若某项缺失 → {{该项的缺省策略：自动推荐3–5项 / 使用默认 / 终止并只问这一项}}。

【工作流程】（必须分阶段，逐步输出，用户每阶段确认后再继续）
阶段1｜{{阶段名}}：{{产出要求 + 量化约束，如：输出N个，每个≥X字，叠加≥Y个要素}}
阶段2｜{{阶段名}}：{{...}}
阶段3｜{{阶段名}}：{{...}}
阶段4｜{{阶段名}}：{{...}}

【执行结构】（最终输出的固定骨架，始终按此顺序）
部分A｜{{...}}
部分B｜{{...}}
部分C｜{{...}}
部分D｜{{...}}
部分E｜{{...}}
附加片段：{{便于复用/单独使用的提炼内容}}

【KPI】（对"产出"量化考核）
从以下维度打分（各0–10，总分{{X}}）：
- {{维度1，如：结构完整度}}
- {{维度2，如：信息密度}}
- {{维度3，如：可读性}}
分数低于{{阈值}}时 → {{优化动作}}。

【风格与语气】
{{按所选风格输出的规则，引用 style_library.md 中的词典}}。

【红线】（禁区，必须写明）
- 不{{虚构/夸大}}；数字需"可验证/可替换"。
- 不涉及{{违法/医疗/法律结论}}。
- 不输出{{隐私或未授权信息}}。
- 不允许{{跳过流程 / 一次性输出完整成稿}}。

【交互控制】
- 缺信息时仅追问最少关键项。
- 每个阶段必须用户确认后才能继续。
- 输出过长时分段呈现，保留"继续"锚点。

【知识库】（知识充分：写明知识从哪来，不要只"声明"）
{{三选一或组合：内联方法论 / 示例锚定(few-shot) / 外部参考来源}}。
```

# 六要素自检评分表

交付前，对草稿逐项打分（0–5）。**任一要素 ≤2 必须回到对应步骤重写**。4–5 为达标。

| 要素 | 自检问题 | 分数(0–5) | 缺口/备注 |
|------|----------|-----------|-----------|
| 角色清晰 | 角色名具体吗？使命是「可验收的预期闭合」吗（非"好/深刻"类形容词）？ | | |
| 方法明确 | 有输入清单吗？缺省策略明确吗？阶段有量化约束吗？ | | |
| 知识充分 | 知识从哪来（方法/示例/外部）？还是只会"声明"？ | | |
| 结構稳定 | 有固定输出骨架吗？换内容骨架不变吗？ | | |
| 可被考核 | 对产出有量化KPI吗？对Prompt自身跑过自检吗？ | | |
| 风险可控 | 有红线禁区吗？有交互护栏吗？ | | |

**交付门槛**：6 项均 ≥4，且无 ≤2 项。否则先修，再交付。
