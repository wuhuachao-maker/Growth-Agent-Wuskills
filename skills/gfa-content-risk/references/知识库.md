# 内容风险知识库（真料）

> 本库为 `gfa-content-risk` 的内置真料，由联网挖掘的真实平台规范沉淀而成。
> 用途：让风险检查不是凭空列清单，而是对照各平台**当前生效**的治理口径。
> 每条机制带来源链接，便于复核与更新。最后更新：2026-08-21。

---

## 一、双轨识别模型（核心框架）

任何内容风险都分两轨，必须同时查：

1. **机器可识别（机审）**——平台算法/关键词/图模能自动抓的：
   极限词、联系方式、二维码、外链、违禁词、搬运查重、AI 未标注。
2. **实质违规（人审/举报）**——机器抓不全，靠人工复核或用户举报发现的：
   制造对立、虚假人设、虚假宣传、诱导分享、侵权、低质流水账。

> 只过机审词库 ≈ 漏掉一半风险。本 skill 两轨都查。

## 二、小红书（社区公约 2.0 + 交易导流细则）

**来源**：小红书《社区公约 2.0》2025-01-19 上线；交易导流违规管理细则 2025-03-12 生效

### 重点红线
| 类型 | 具体表现 | 处置 |
|---|---|---|
| 反对制造对立 | 放大群体差异、煽动对立话题引流 | 2025 至今处置账号 53.42 万、笔记 459.8 万篇 |
| 拒绝虚假人设 | 伪造财富/学历/收入/情感经历 | 2025 上半年处置虚假人设账号 1 万 |
| AI 辅助标注 | 用了 AI 辅助工具须主动标明 | 未标 + 低质 AIGC 处置 60 万篇 |
| 有序经营 | 违规营销、恶意竞争、伪造口碑、伪装素人 | 2025-03 至 08 封禁虚假账号超 1200 万 |
| 交易导流（新增） | 引导站外交易：留私域/三方联系方式、发外链/口令/二维码/水印/小程序 | 警告→限流→封号，扣信誉分 0–12 |

### 对本 skill 的关键信号
- **严禁**在正文/图片/评论留微信号、二维码、外链、"看主页""私我"等导流话术。
- **AI 生成内容必须标注**（文末"AI 辅助创作"），且人工改写 ≥30%。
- 标题党、伪装素人测评、伪造数据，直接判高风险。

## 三、微信公众号（运营规范 + 原创治理）

**来源**：微信公众平台运营中心公告；第三方整理《微信公众平台运营规范》
- 红线汇总：https://pd.qq.com/g/h1e3unnoq8/post/B_251cce68158d02001441152190162571170X60
- 诱导分享细则：https://www.shiqingwu.com/portal.php?mod=view&aid=1684
- 治理通报：https://so.html5.qq.com/page/real/search_news?docid=70000021_5786855092c61652

### 五大封禁红线
1. 内容违规：涉黄赌毒暴恐、政治敏感、谣言、低俗暴力、翻炒旧闻误导。
2. 版权侵权：抄袭洗稿、滥用原创声明、盗版资源。
3. 运营欺诈：刷量、诱导分享、外挂。
4. 身份造假：假冒政府/企业/公众人物、恶意关联品牌名。
5. 其他高频：违规采集隐私、账号交易、谐音/符号藏违规、骚扰群发、乱插未备案外链。

### 诱导分享三型（高频雷区）
- 强制分享：分享后才能看全文/继续。
- 利诱分享：集赞、抽奖、红包换转发。
- 胁迫煽动："不转不是中国人""转疯了""必转"。

> 2025-05 单月治理违规原创 64231 篇、抄袭 1229 篇、封禁侵权账号 1065 个。

### 对本 skill 的关键信号
- 公众号硬广**必须显著标注"广告"**，且不能诱导分享。
- 引用他人内容需授权，"原创"标签不可乱用。
- 医疗/金融/时政类需资质，无资质别碰。

## 四、抖音（社区自律公约 + 审核机制）

**来源**：抖音《社区自律公约》官方全文；第三方审核机制解读
- 公约全文：https://www.douyin.com/rule/policy
- 审核流程：http://www.3835.com/douyin/22478.html
- 限流六类：https://qitongshe.com/article/5680423252200372

### 审核流程（双审 + 消重 + 流量测试）
1. 机器初审：画面/标题/关键词识别潜在违规。
2. 人工复审：机器标记内容复核。
3. 消重检测：搬运查重，重复作品限流/删。
4. 流量测试：初始 200–300 播放池，按完播/互动决定是否晋级。

### 限流六大类
| 类型 | 表现 |
|---|---|
| 内容违规 | 色情低俗/血腥/迷信/造谣/网暴/侮辱诽谤 |
| 侵权 | 未经授权搬运/剪辑/用他人肖像商业宣传/虚构人设 |
| 营销违规 | 隐蔽软广、评论区导流、批量同质带货、引导加微信 |
| 数据造假 | 刷赞/评/粉/完播 |
| 恶意互动 | 煽动对立、冒充官媒、编造灾情谣言 |
| 违法 | 涉赌/诈骗/违禁品 |

### 对本 skill 的关键信号
- 口播/字幕/评论区**引流到微信私域**是营销限流池高频触发。
- 虚构人设、摆拍伪纪实、标题党，机器+人工双抓。
- 前 3 秒违规（血腥/擦边）直接不进池。

## 五、广告法极限词（商业内容通用高压线）

**来源**：《广告法》第九条；市监合规清单；律师整理禁用词
- 市监清单：https://scjg.huangshi.gov.cn/ztzl/sqxzjcgszl/202512/t20251226_1294470.html
- 禁用词整理：https://lvshi.sogou.com/article/detail/DP4Q2M9VUSSC.html

### 禁用词大类（节选高频）
| 类 | 词例 | 替代 |
|---|---|---|
| 绝对化 | 最、第一、唯一、国家级、顶级、极品、绝无仅有 | 较/领先/少有/前沿 |
| 虚假夸大 | 永久、万能、纯天然100%、特效、根治、无敌 | 长久/多场景/有效 |
| 时限模糊 | 最后一波、随时涨价、仅此一次、错过再等一年 | 限今日24点前/截止X月X日 |
| 迷信诱导 | 招财进宝、逢凶化吉、护身保平安 | （内容创作一般不用） |
| 欺诈紧迫 | 秒杀、抢爆、再不抢就没了、万人疯抢 | 限时优惠/数量有限 |

### 罚则
- 绝对化用语：处 **20 万–100 万**罚款，情节严重吊销执照（《广告法》第五十七条）。
- 虚假广告：民事三倍赔偿 + 信用公示。

### 特殊行业禁区（速记）
- 食品：不得宣称治疗/预防/抗癌/减肥，须标"不能代替药物"。
- 保健：按批文功效，不得扩大（"辅助降血脂"≠"根治高血脂"）。
- 教育：不得"保过/最快拿证/就业率100%"。
- 金融：不得"保本保收益/无风险"，须标"投资有风险"。
- 化妆品：普通品不得宣称祛斑/美白/治疗痤疮。

### 对本 skill 的关键信号
- 凡带"卖货/推广"属性的内容，先过极限词库。
- 用具体数据替代绝对词（"销量第一"需权威第三方全行业证明，否则禁用）。

## 六、通用最小修改动作（给 AI 的默认修正策略）

1. **极限词** → 换成相对/可验证表述（见上表替代列）。
2. **导流信息** → 删除微信号/二维码/外链；如需留资走平台官方组件。
3. **AI 内容** → 文末标注"AI 辅助创作"。
4. **虚假宣称** → 改为"有助于/据数据显示"，附来源。
5. **诱导分享** → 删"转发抽奖/不转不是…"，改为自然呼吁。
6. **侵权** → 标注出处/获授权，或替换原创素材。
7. **制造对立** → 改中性表述，不放大群体差异。
8. **时限模糊** → 给具体截止日期。
