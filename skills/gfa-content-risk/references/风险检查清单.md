# 内容风险检查清单（可回填）

> 本清单是 `gfa-content-risk` 的"双轨扫描表"，初版来自 `知识库.md`。
> **回填闭环**：用户实发后若有"被限流/误报/漏检"，在此追加一行，本 skill 越用越准。
> 每次回填记：日期 + 平台 + 触发项 + 来源（平台公告/实测）。

---

## 机审轨（机器可抓）

- [ ] 极限词（最/第一/唯一/国家级/顶级/极品/永久/万能/纯天然100%）→ 见知识库五
- [ ] 联系方式（微信号/手机号/邮箱明文）
- [ ] 二维码 / 小程序码 / 外链 / 口令（淘宝口令、私域引流）
- [ ] AI 辅助未标注（文末无"AI 辅助创作"）
- [ ] 搬运信号（"全网最/独家首发/原装"等查重高风险词）
- [ ] 不文明用语（抖音违禁词表）

## 实质轨（人工/举报）

- [ ] 制造对立（放大性别/地域/职业差异引流）
- [ ] 虚假人设（伪造财富/学历/收入/情感经历）
- [ ] 虚假宣传（无据的"根治/特效/100%"）
- [ ] 诱导分享（强制/利诱/胁迫煽动"不转不是…"）
- [ ] 侵权（未授权引用/洗稿/用他人肖像）
- [ ] 标题党（标题与正文不符的夸张）
- [ ] 低质流水账（每 100 字无有效信息点）
- [ ] 时限模糊（"最后一波/随时涨价"无具体截止）
