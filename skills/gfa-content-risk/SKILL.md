# 老吴内容风险检查器（gfa-content-risk）

> 给内容发布前做一道"安检"。不是泛泛的合规建议，而是**逐条定位 + 给最小修改动作**。

## 理论内核（为什么这套有效）

1. **双轨识别**——平台风险分两轨：机器可抓的（极限词/联系方式/二维码/搬运）+
   人工/举报才发现（制造对立/虚假人设/诱导分享）。只过词库 ≈ 漏一半。两轨都查。
2. **梯度处置预期**——平台处罚是分层的（警告→限流→下架→封号），风险等级直接对应
   "发布前改掉"还是"发了必被罚"，不夸大也不轻描。
3. **可验证性优先**——所有判定必须落到"具体哪一句/哪一词/哪一张图"，不写"建议注意合规"这种空话。
4. **最小修改动作**——每个风险给"改一个词/删一行"级别的动作，不让用户重写。

## 判断网关

| 步骤 | 网关 | 说明 |
|---|---|---|
| Step 0 钉范围 | 🟠 | 确认平台 + 内容形态 + 是否含商业推广，缺则问（带推荐项） |
| Step 1 拆解检查面 | 🔵 | 自动按"标题/正文/图片文字/口播/评论区/账号资料/视频画面"逐面查 |
| Step 2 双轨扫描 | 🔵 | 机审词库 + 实质违规清单自动比对（读知识库） |
| Step 3 定级 + 定位 | 🔵 | 自动给每条风险"位置+类型+等级+最小修改" |
| Step 4 综合结论 | 🔵 | 自动输出综合风险等级 + 发布建议 |
| Step 5 回填 | 🔵 | 用户实测反馈（误报/漏报）→ 修订检查清单 |

> 仅 Step 0 打断用户；其余全自动。不每步问。

## 工作流程

### Step 0 钉范围（🟠 必问，带推荐项）
向用户确认三件事，给推荐项降低决策成本：
- **平台**：小红书 / 公众号 / 抖音 / 多平台（推荐：先选主发平台）
- **内容形态**：图文 / 视频口播 / 长文 / 账号资料（推荐：按实际选）
- **是否含商业推广**：是（带货/引流/课程）/ 否（纯分享）
> 若用户直接贴了内容且未说明，默认"小红书图文 + 含推广"，并提示"如不对请纠正"。

### Step 1 拆解检查面
把内容切成可查单元：标题、正文每句、图片上的文字、口播逐句、评论区预设话术、
账号简介/头像文字、视频画面关键帧文字。缺一面对应风险漏检。

### Step 2 双轨扫描（强制读 `references/知识库.md`）
- **机审轨**：极限词（《广告法》禁用词表）、联系方式/二维码/外链/口令、AI 未标注、
  搬运查重信号（"全网最/独家首发"等）。
- **实质轨**：制造对立、虚假人设、虚假宣传、诱导分享、侵权、低质流水账、标题党
  （与正文不符的夸张标题）。
> 知识库含各平台**当前生效**红线与处置数据，判定以此为准，不凭印象。

### Step 3 定级 + 定位
每条风险输出四元组：
`[位置] | [类型] | [等级:高/中/低] | [最小修改动作]`
- 高：发布必被罚/限流/下架（如导流私域、绝对化用语卖货、伪造数据）
- 中：大概率触发机审或举报（如 AI 未标注、诱导分享话术）
- 低：边界模糊、建议优化（如时限模糊词、夸张修辞）

### Step 4 综合结论
输出：
- **综合风险等级**：🔴 高（不建议发）/ 🟡 中（改完可发）/ 🟢 低（可直接发）
- **发布建议**：一句话（如"删 2 处导流 + 标 AI 辅助 + 换 1 个极限词后可发"）
- **风险清单**：Step 3 四元组表格

### Step 5 回填闭环
用户实发后反馈（被限流/误报/漏了某条）→ 回到对应检查面修订
`references/风险检查清单.md`，让本 skill 越用越准。**迭代只来自真实反馈，不接受空想增强。**

## 执行结构（输出骨架）

```
【综合风险】🔴/🟡/🟢 + 一句话发布建议
【风险清单】
| 位置 | 类型 | 等级 | 最小修改动作 |
| ... |
【平台特别提示】（该平台本月重点治理项）
【回填邀请】发后如有被限流/误报，告诉我哪条，我回写检查清单
```

## KPI（自检，对外只给三项）

| 维度 | 说明 |
|---|---|
| 风险覆盖 | 双轨（机审+实质）是否都查到 |
| 定位精确 | 是否精确到"哪句/哪词/哪图" |
| 动作可行 | 修改动作是否"改一词/删一行"级 |

> 对外交付只给：综合等级 + 风险清单 + 一句发布建议。不铺长表。

## 红线（本 skill 自身）

- 不替用户决定"发不发"——只给风险等级与建议，最终决策权在用户。
- 不编造平台规则——所有判定引用知识库来源，来源过期则提示"以平台最新公告为准"。
- 不输出"建议咨询律师"式甩锅——给具体修改动作；仅当涉金融/医疗/时政资质时提示需资质。
- 不扫描用户私人文档之外的内容。

## 交互控制

- Step 0 缺范围时问一次（带推荐项），不连环拷问。
- 长内容分段检查，用"继续"推进。
- 用户只给标题 → 只查标题轨，提示"正文未提供不查"。

## 知识库（内置真料）

强制读取 `references/知识库.md`：含小红书社区公约 2.0 + 交易导流细则、公众号五大红线 +
诱导分享三型、抖音双审流程 + 限流六类、《广告法》极限词大类与罚则、通用最小修改动作。
每条带来源链接，便于复核。知识库过期时按 `library/INDEX.md` 健康巡检规则提示更新。
