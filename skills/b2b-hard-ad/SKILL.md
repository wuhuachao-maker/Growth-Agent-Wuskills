# B2B 硬广文案方法论

## 核心哲学

B2B 文案是"沉默的销售员"：买家是决策链（业务负责人 / CTO / 使用者 / 采购财务），理性且风险厌恶。驱动力是**信任 + ROI + 可控风险**，不是零售的稀缺 / 从众 / 紧迫。转化动作是**留资 / 预约 Demo / POC**，不是直接购买。本 skill 教你用可复用框架产出"靠文字本身站得住"的 B2B 硬广。

## 工作模式

- **研究前置**：动笔前先搞清楚产品子类与"真实采购理由"（如客服 Agent = 降本 + 夜间覆盖，不是"AI 很酷"）。
- **卖结果不卖功能**：灵魂是"把一块业务的确定性结果外包给 Agent"。
- **完整自包含**：产出评分标题 + 正文 + 单一 CTA + 转发话术 + 留资承接话术（纯文本）。

## 标准流程（8 步）

1. **收简报 + 判产品子类**：客服/营销 Agent（成本对比）、内部流程 Agent（效率）、行业垂直 Agent（案例驱动）→ 锁定真实采购理由。
2. **调研受众**：找真实痛点、决策者顾虑、1–2 篇同行标杆推文、竞品定位。
3. **找真实采购理由（企业 ROI 视角）**：把表层功能翻译成商业账：量化降本（年省 X 人天）/ 增效（响应快 Z 倍）/ 风险规避。
4. **选结构模板 + 范式**：三幕剧 / BAB / SCQA / PASTOR / StoryBrand / 4P / AIDA / Hook-Story-Offer 八选一（用户可指定，否则推荐并说明理由）。
5. **写标题（量化评分）+ 钩子候选**：3 个候选标题打分（总分≥16 用主）；首句即最高张力场景，认知颠覆点在 217–283 字内落地。
6. **写 8 段正文**：钩子 → 场景锚定 → 痛点放大 → 旧范式 vs 新范式（全文脊梁，反复 2–3 次）→ 能力地图（之前→现在 + 能力→收益映射）→ 信任状 → 效果证据 → 风险消解 + CTA 合并。正文 2000–2800 字。
7. **转发资产 + 反对意见处理**：提前处理 2–3 个最可能出现的 B2B 反对意见；埋 3 个文本转发钩子（社交货币 / 比较价值 / 利他）。
8. **输出完整文案**：架构逻辑图 + 标题块 + 纯文本正文 + 单一 CTA + 转发话术 + 留资承接话术。

## 输出格式（模板 A/B/C）

- **A · 完整硬广**（默认）：逻辑图 + 标题块 + 正文 + CTA + 转发/留资话术。
- **B · 标题+开头包**：只给 3 标题（带分）+ 2–3 钩子开头，供先定调。
- **C · 结构骨架**：8 段逻辑图 + 每段作用/读者心理，供协作填充。

## 典型场景

- AI Agent / SaaS 新品发布硬广。
- 行业案例驱动推文（标杆客户故事）。
- 效率提升型软文（内部流程 Agent）。

## 说话风格

专业、有证据密度、读者即英雄（你的产品是向导）；不用零售式催促；每段能力都接"意味着你的 X 指标提升 Y%"。

## 语言

中文。

## 红线

- 不承诺"保证成交/涨 X 倍"；B2B 爆款 = 圈层转发 + 高留资转化，非 10w+ 阅读。
- 不编造数据/资质；不替用户发布、不接私有数据审查模块。
